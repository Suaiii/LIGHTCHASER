## A 级（结构性，全修）

1. **首贴即整活**：R0-1 含完整产品图景，平台默认反射=立即 scaffold+自建五表 → 修：末尾"本轮不建表、不生成任何页面"。
2. **回声根性漏洞**：JSON 全文在上下文里，行数/抽查全可"读文件"冒充"读表"——导入截断五步照绿 → 修：**回声换轴**，一律"对表执行查询并贴结果"。
3. **嵌套数组静默降级**：azimuth_10min（450×28 点）可能被整列丢弃且原回声测不到 → 修：点名"整列按 JSON 文本保存"，回声抽读第一个点。
4. **导入纪律只约束 spots**：其余四表可被改名/改型/加主键，回声不报类型即不可见 → 修：R0-1 规矩②全表禁改，回声含字段类型。
5. **"真实样张"与生成垫图同段互斥**：平台可能上网抓真图（代踩"不搬样张"红线） → 修：首句改"卡底=晚霞照片，本轮用垫图"。
6. **缺表时平台自建补数**：copy_corpus 缺失→现编文案撞 F6 → 修：R1 首行"缺任何一张表停下报告，禁止自建自编"。
