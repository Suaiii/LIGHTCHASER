## 一、何时触发

评审 UI 改动、打设计分、选动效、守"前5秒"红线时调用本 Skill。适用场景：`public/*.jsx` 原型改版评审、Figma 稿评审、平台还原度守门。触发词：**设计评分、design score、还原度、动效选择、前5秒、卡片美感**。

## 二、规则正文

### 2.1 前 5 秒法则（最高优先级，覆盖其他一切规则）

评委刷到卡片的瞬间就是评审现场。任何设计决策先过这四问：
1. **0.5s**：评分大数字可读了吗？（数字是 payload——永不动画化）
2. **1.5s**：能看懂"今晚值不值得出门"吗？（等级标签+色彩情绪一起说话）
3. **3s**：产生第一次交互欲了吗？（行动句+可见的滑动暗示）
4. **挡路即砍**：前5秒内出现的装饰、引导浮层、多余信息——删。

### 2.2 Design Tokens（权威值，冲突时以 `tokens.md` 为准）

**色彩**：基底 `#0a0a0d`；强调色 `--accent:#ff8a3d`（唯一）、`--accent-2:#ffd49a`（暖辅，仅文字点缀）；文字阶 `#fff`→`0.92`→`0.75`→`0.55`→`0.35`；边框 1px `rgba(255,255,255,0.08–0.12)`（唯一 hairline）。

**天空色卡 8 锚点**（t∈[0,1]，产品灵魂，一个值都不许改）：
`0.00 #5C749A` 清冷灰蓝 → `0.15 #3A4A6B` 深灰蓝 → `0.35 #B08050` 暗金黄 → `0.50 #E0A060` 橘黄 → `0.65 #DE6B48` 橘红 → `0.78 #C84858` 深红 → `0.90 #8A4068` 紫红 → `1.00 #5A3870` 紫。

**字体**：中文/UI 用 Noto Sans SC；展示大数字用 Fraunces；时刻/坐标/数据用 JetBrains Mono。字阶：展示 96/64/54，标题 22/18/16，正文 14/13/12，说明 11/10/9。

**圆角**：4(微章)·8(小控件)·12(控件)·18(卡片)·27(大面板)·999(pill)。**间距**：4px 基网格，常用 8/12/16/24。

**动效**：页级 420ms `cubic-bezier(.16,.9,.18,1)`（silk）/ 组件级 350ms（silk-lite）/ 控件级 120–150ms `cubic-bezier(.3,.7,.4,1)`（snap）。5 个命名 seed：**silk**(丝滑·卡片入场)、**snap**(利落·控件反馈)、**spring**(弹性·主CTA/发布成功)、**pulse**(脉动·倒计时/直播中状态)、**float**(漂浮·仅限氛围层)。

**光效**：深色底"发光"取代"投影"——主色光晕 `0 0 24px rgba(255,138,61,0.25)` 一档、`0 0 48px …0.15` 二档，同一光源方向感（上方），不混投影。

### 2.3 连贯性法则（10 轴，每轴只选一，混用=lint error）

圆角/阴影(glow非投影)/强调色(仅追光橘)/间距(4px网格)/图标(单一线性族，禁emoji当UI图标)/字阶(≤3族)/动效(一套时长+一族缓动)/边框(1px低对比，不做层级分隔)/状态层(hover/press同一透明度阶梯)/深色底(`#0a0a0d`唯一)。

### 2.4 文案硬约束

hook ≤26字、tip每条≤15字恰3条；全文形容词≤2个、感叹号≤1个；不承诺天气（禁"一定/必然"）；不出现第三方App名；每次输出含≥1个时间锚点；只能引用输入JSON中真实存在的机位名/方向/时间/距离，严禁编造地点。（详见 D 提示词包硬规则原文）

### 2.5 图层亮度纪律（🔁 D-c 裁定更新，覆盖旧"金线>见光点>气泡"三层排序）

**默认地图视图气泡为主体**，无常驻金线/见光点；**按需路线出现时压过气泡**（用户主动查看路线才提亮路线层，气泡层临时让位）。旧口径"金线>见光点>气泡"三层常驻排序**作废**。

## 三、校验清单（改 UI 后必须跑，<80 不给人看）

对目标文件按六类打分（满分100，逐条扣分须引用行号证据，不许凭感觉）：

| 类目 | 权重 | 扣什么 |
|---|---|---|
| 前5秒信息效率 | 30 | payload被动画化(-10)；0.5s内评分不可读(-8)；首屏焦点>3个(-5)；装饰挡主信息(-5)；无滑动暗示(-4) |
| 连贯性 | 20 | 每混一轴-5，封顶-20 |
| 层级与排版 | 15 | 数字/单位比例失衡(-4)；同字重无主次(-5)；行高局促(-3)；字号偏离tokens(-3) |
| 色彩纪律 | 15 | 第二强调色(-5)；纯黑#000(-4)；语义色滥用(-4)；写死hex绕过token(-2/处) |
| 状态与可达性 | 12 | 缺空态/加载/错误(-4/个)；对比度<4.5:1(-5)；触点<44px(-3)；无焦点可见(-3) |
| 动效纪律 | 8 | 未命名随手fade(-3)；动效阻塞内容(-4)；无reduced-motion(-3) |

输出=总分+逐类分+证据行号+按"提分收益"排序的fix-first清单→修→重打，循环至≥80（地板非天花板，到85就停）。

**Gate 2 盲测预演**（≤3分必须修）：系统状态可见？撤销容易？一致与标准（滑动方向符合抖音肌肉记忆）？识别优于回忆？零讲解可懂（陌生人5秒说出"这卡让我干什么"）？
