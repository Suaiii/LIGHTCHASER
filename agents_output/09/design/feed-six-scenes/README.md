# 封面卡六场景 · 平台素材包（台词本）

来源：**PR #45**（@Flyme886，`assets/figma/lightchaser-six-photo-scenes.svg` 一张 1450×1994 拼版稿）。
本目录 = 把那张拼版**拆成平台能一张张吃下去的件**，加规格、加数据、加合规待办。

## 包里有什么

```
feed-six-scenes/
├── README.md          ← 你在看的这份：上传顺序 + 怎么说
├── card_spec.md       ← 版式规格（坐标/色值/字号全表 + 数据绑定 + 已知偏差）
├── scenes.json        ← 6 个场景的文案槽位结构化数据（平台建表直接照抄）
├── cards_jpg/01–06.jpg  ← **首选上传件**：单卡 2x 位图 860×1720
├── cards/01–06.svg      ← 单卡矢量（430×860，自包含，平台若吃 SVG 就传这个）
└── photos/01–06.jpg     ← 6 张纯背景实拍（不带 UI，做卡面底图用）
```

## 上传顺序（按这个顺序，平台 AI 才不会自由发挥）

1. **先传 `cards_jpg/01.jpg` 一张** + `card_spec.md` → 让它照着做出**一张**卡。
   一次只给一张，是因为一次丢六张，它会去"平均"六张的差异，做出一张四不像。
2. 一张做对了，再传 `scenes.json` + 剩下 5 张图 → 让它把同一套版式**换数据复用**。
3. `photos/*.jpg` 只在它说"读不到图里的背景"时才补传。
4. 提示词见 `platform-prompts/round2-B档打磨/07-封面卡六场景.md`（分三段发，别一次贴完）。

## 上传前必做的两件事（F6 红线，不做别传）

1. **补「示例数据」角标**：六张卡的分数/倒计时/距离全是设计稿编的值，现在**一张都没有角标**。规格见 `card_spec.md §5-B`（44×16 胶囊，评分卡正下方，常显、不许 hover 才出）。
2. **确认背景照片来源**：6 张 JPEG 的 `credit` / `consent_ref` **全空**，需 @Flyme886 补。来源不明的只能当"版式参照"给平台 AI 看，**不能作为对外演示的卡面**。
   ⚠️ 场景 06（夜市）另有隐私问题：多张可辨认人脸 + 招牌上手机号清晰可读，对外用前必须换图或打码。

## 一句话说明这包解决什么

平台 AI 做卡片时最容易翻车的两点是**版式比例**和**信息层级**。这包用"一张 2x 位图（它看得懂）+ 一张坐标表（它抄得准）+ 一份 JSON（它填得对）"把这两点钉死，剩下的它只需要渲染。
