# 晚霞评分公式 v2 · 一页纸规格（AGENT_02）

> 目标：让"今晚值不值得为天空出门"这个判断**可解释、可复算**。评委问"分数怎么来的"，答案是这一页，不是黑盒。参考实现见 `light_engine.js`（`score()`）。

## 1｜总公式

```
score = round( 100 · clamp( 0.35·f_cloud + 0.20·f_humidity + 0.20·f_visibility + 0.15·f_sun + 0.10·f_air , 0, 1 ) )
```

权重合计 = 1.00。因子各自归一到 [0,1]。分数 → 等级：**≥75 值得跑出门 ／ 45–74 顺路看看 ／ <45 今天歇着**。

## 2｜五个因子的曲线（≤5 因子，可解释优先于拟合精度）

| 因子 | 权重 | 输入 | 曲线定义 |
|---|---|---|---|
| **f_cloud** 云 | 0.35 | 低/中/高云量 % | `cmh = 0.6·中云 + 0.4·高云`（中高云最易被染色）；`base = 平台钟形(cmh, 峰区[30,60], 硬界[5,95])`；低云惩罚 `lowPenalty = clamp(1 − 0.8·max(0,低云−40)/50, 0.2, 1)`；`f_cloud = base·lowPenalty`，且**低云 ≥70 → 封顶 ≤0.2**（低云满盖直接压死） |
| **f_humidity** 湿度 | 0.20 | 相对湿度 % | 平台钟形，峰区 [40,70]，硬界 [10,95] |
| **f_visibility** 能见度 | 0.20 | km | ≤1km→0；`(v−1)/9`；≥10km→1（饱和） |
| **f_sun** 时窗 | 0.15 | 距日落分钟 | \|Δ\|≤40→1；40–120 线性降至 0.3；>120→0.2。（日峰值评分取 Δ=0→1；realtime 传真实分钟，让同一引擎既算"此刻"也算"峰值"） |
| **f_air** 天气码 | 0.10 | WMO code | 晴0/1→1，少云2→0.95，阴3→0.85，雾45/48→0.5，毛毛雨51–57→0.3，雨61–67→0.2，雪71–77→0.1，阵雨80–82→0.25，雷暴95+→0.15 |

> **平台钟形(x, [lo,hi], [hardLo,hardHi])**：区间 [lo,hi] 内=1；lo 以下线性降到 hardLo 处=0；hi 以上线性降到 hardHi 处=0；硬界外=0。

## 3｜三个真实算例（第三者仅凭本页可手工复算，与参考实现 ±1）

所有算例取 **Δ=0（日落峰值），f_sun=1**。

### 算例 A · 高分（中高云通透晴）→ **100 分 · 值得跑出门**
输入：低云15 中云45 高云30 ｜ 湿度55 ｜ 能见18km ｜ code2
- cmh = 0.6·45 + 0.4·30 = 39 → 落 [30,60] → base=1；lowPenalty(15)=1 → **f_cloud=1**
- f_humidity: 55 ∈[40,70] → **1**　f_visibility: 18≥10 → **1**　f_air(2)=**0.95**
- raw = 0.35·1 + 0.20·1 + 0.20·1 + 0.15·1 + 0.10·0.95 = **0.995** → round(99.5)=**100**

### 算例 B · 中分（低云偏多微湿阴）→ **66 分 · 顺路看看**
输入：低云60 中云25 高云15 ｜ 湿度80 ｜ 能见8km ｜ code3
- cmh = 0.6·25 + 0.4·15 = 21 →（<30）base=(21−5)/(30−5)=**0.64**；lowPenalty=clamp(1−0.8·(60−40)/50,0.2,1)=**0.68** → f_cloud=0.64·0.68=**0.435**
- f_humidity: 80>70 →(95−80)/(95−70)=**0.60**　f_visibility:(8−1)/9=**0.778**　f_air(3)=**0.85**
- raw = 0.35·0.435 + 0.20·0.60 + 0.20·0.778 + 0.15·1 + 0.10·0.85 = 0.1523+0.12+0.1556+0.15+0.085 = **0.663** → **66**

### 算例 C · 低分（雨天低云满盖）→ **29 分 · 今天歇着**
输入：低云95 中云20 高云10 ｜ 湿度92 ｜ 能见4km ｜ code63(雨)
- cmh = 0.6·20 + 0.4·10 = 16 → base=(16−5)/(30−5)=**0.44**；lowPenalty=clamp(1−0.8·(95−40)/50,0.2,1)=clamp(0.12,0.2,1)=**0.20**（触 0.2 下限）→ f_cloud=0.44·0.20=**0.088**（低云≥70 封顶不触发，0.088<0.2）
- f_humidity: 92>70 →(95−92)/25=**0.12**　f_visibility:(4−1)/9=**0.333**　f_air(63)=**0.20**
- raw = 0.35·0.088 + 0.20·0.12 + 0.20·0.333 + 0.15·1 + 0.10·0.20 = 0.0308+0.024+0.0667+0.15+0.02 = **0.292** → **29**

## 4｜与初赛 v1 的差异（为何叫 v2）
- 云量由单值拆成**低/中/高分层**（低云是晚霞杀手，中高云是染色画布）——这是最大升级；
- 新增 **f_sun 时窗因子**：同一引擎既能算"日落峰值分"，也能算"此刻实时分"；
- 新增 **f_air 天气码**独立惩罚项，雨雾霾直接拉低；
- 全因子归一 [0,1] + 显式权重，**可逐项复算**（算例即证据）。

## 5｜调参口（回测不符时只动这里，不加因子）
峰区边界（云 30–60 / 湿 40–70）、低云封顶阈（70）、能见饱和点（10km）、f_air 档位。**因子数锁定 5 个**（本 agent §8 红线）。回测方法见 `check_report_02.md` C6。
