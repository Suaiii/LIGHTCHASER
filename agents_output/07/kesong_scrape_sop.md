# 可颂机位信息采集 SOP（工具链已验证 · issue #3）

> 目的：把可颂上已有的深圳机位**事实信息**（位置/朝向/拍法/最佳时段）采进 `spots.v1.json`，给 AGENT_01 机位库做交叉校准与增补。
> **工具链探测结论（2026-07-12）**：本机无浏览器控制 MCP，但 **Playwright CLI v1.61.1 可用**（chromium-1223 已缓存，另有系统 Chrome/Edge）→ 走 **Playwright Node 脚本**路径，可行。

## ⛔ 红线（先读，违反即废）
1. **只取事实，不搬内容**：坐标/地名/朝向/时段/拍法要点可以记录；**样张图片一律不下载、不保存、不引用**——样张必须走 AGENT_07 授权或 7.28 自拍（AGENT_00 F6 一票否决）。
2. 文字表述**全部重写**进 `stand_desc/copy_slots`，不粘贴笔记原文（AGENT_01 C6）。
3. 截图仅作**内部工作证据**（记录信息来源，存 `agents_output/07/scrape_evidence/`，不入任何对外物料）。
4. 采集频率克制：单账号浏览节奏模拟真人（页间隔 ≥3s），不批量抓接口。

## 工序（人机配合，约 1–2 小时/批）

**Step 1 · 人：收集分享链接（手机端，10 分钟）**
在可颂 App 内搜"深圳 晚霞/机位/citywalk"等词 → 对相关帖子点"分享→复制链接" → 链接粘进 `scrape_targets.txt`（一行一条，可附一句备注）。
> 说明：可颂 H5 分享页通常免登录可打开；若某链接要求登录，标记后跳过（不破解、不带凭证爬）。

**Step 2 · AI：脚本批量走查（Playwright）**
脚本（届时按 targets 现写，~50 行）：逐条打开分享页 → 截图存证 → 提取**文本层**信息（标题/正文/位置标签）→ 输出 `scrape_notes.jsonl`（字段：url/地名/疑似坐标或地标/拍法要点摘录/时段线索/截图路径）。
运行：`npx playwright …`（chromium 已缓存，无需再装）。

**Step 3 · AI+人：事实入库**
- AI 把 notes 重写为 AGENT_01 schema 字段（`stand_desc` 保守表述+`待核`；坐标经 `geo_verify.mjs` 反查核验）。
- 与现有 25 机位**交叉校准**（同点位比对 bearing/时段），差异记 `spots_readme.md`。
- 新增机位走正常校验：`validate_spots.py` 0 error。
- 顺带产出**外联线索**：优质帖作者记入 `consent_ledger.csv`（状态=待触达）——采集与授权外联一鱼两吃。

## 边界与降级
- 可颂内容若以视频为主、文本层稀薄 → 降级为"人看视频口述要点，AI 记录入库"（工具链依然省掉找帖/存证的机械劳动）。
- 分享页结构若强依赖 JS 渲染 → Playwright 本就带完整渲染，无碍；若有验证码/风控 → 停，转纯人工，不对抗。
