# 抖音大区赛深圳赛道三 7.28-8.1

以拍摄的“出片”为跳板，往餐饮、周边活动、艺术展馆、社交场所和本地生活延伸，尝试挤压小红书在本地生活攻略里的位置。

故事：抖音一直在扶持可颂相机，但现在抖音和可颂之间还没有形成一条很顺的链路，也还没有真正撬动小红书的本地生活攻略心智。与此同时，我们已经做了两年的可颂生态，在线路、机位和拍摄指引上有一些积累。至少在部分场景里，我们有信心做得比小红书更直接、更有效。

所以现在要做的，不是再造一个可颂，也不是再造一个小红书，而是让抖音用户自然地走向可颂。我们已经有可颂机位分享、拍摄路线和现场引导能力，追光要做的是把这些能力放到抖音用户刚刚产生出门冲动的那一刻。

追光不是一个单纯的本地生活工具，也不是摄影 App。它更像抖音用户从“刷到心动”到“真的出门”之间的中间者。这个点其实很简单：人们很多时候不是为了拍照而出门，而是想把生活里值得被看见、被记录、被分享的瞬间变成自己的体验。追光抓住的是这种“想出片，也想生活”的冲动。

这里的“出片”不只是摄影，而是一种抖音语境下的生活方式表达。餐饮可以出片，美术馆可以出片，演唱会可以出片，骑行可以出片，旅行可以出片，城市漫步也可以出片。它的出发点很简单，但一旦满足了我们的前提条件，其前景是不可估量的。

商业模式上，追光的入口应该很简单：用户刷到一个美好生活场景，追光告诉他“现在你也可以去”。但这个入口后面可以接很多东西，包括可颂机位、团购、直播、餐饮、旅游和展演活动。小红书解决的是“我已经想查攻略了”，追光解决的是“我还没开始查，但我已经被抖音里的美好生活打动了”。

更准确的产品结构是：抖音制造心动，追光判断此刻是否值得行动并给出最短路径，可颂承接机位、攻略、作品和深度内容。因此追光不是和可颂竞争，而是抖音通向可颂、通向本地生活攻略市场的一层过渡。它让抖音的流量不只停在点赞收藏，而是继续走向地点、路线、攻略、消费和发布。
