## 0. 为什么推倒 v3 的第一性原理（office hour 7.18）

v3 的第一性锚点是赛题原话"用户在刷到的一瞬间，是否就能被打动、被满足"（体验完整性 30%）。**office hour 把晋级的生死线往前提了一层**：

> **产品能不能真的进入抖音 feed 流、面对全国真实用户场景持续运转。如果进不去，被打动与否都白搭——永远进不了决赛。**

这不是否定"被打动"，而是给它加了一道更硬的前置闸门。由此负责人连下三判断：

1. **全国化 + 场景下沉到生活**：使用场景转向全国，不止深圳/上海；内容不止日落日出，最好快速下沉到生活（好吃/好玩/出片/citywalk）。
2. **两堵权限墙已确认**（注意：是"本期产品不做"，不是"否定这些方向"）：
   - ① 电商 / 本地生活权限**本期拿不到** → "市场接轨、可颂/团购导流"这套商业链路**本期提交产品里不做**（不是它不成立，是本期没权限落地）。→ **商业故事整体保留为未来 development roadmap**，路演可作"未来延展"诚实呈现（标注需权限）。
   - ② 追光相机**连不到抖音的视频/内容生产界面** → 板块三"真拍摄管线"**本期产品不做**，同样归档为未来效果展示（见 §7）。
3. **产品不是工具/攻略/指导类**（不告诉你"这里能拍、那里不能拍"），而是一个**实时变化的小社区**——在**对的时间点**轻拽你一下："这地方现在挺好玩，想去吗？"你刷到的是"附近的人此刻在哪、在玩什么"，去不去自己定。

## 1. 新第一性检验

**新锚点**：产品能否作为一张真实的 feed 卡活在抖音信息流里，让全国任意地点、任意时段的人，快速看到"周遭其他人此刻发的、值得一去的内容"，并自然产生一次"想去/去看看"的冲动。

每份 v4 任务书开头必须回答：**这个任务如何让"产品真进 feed 流、面对全国真实用户"更成立**（替换 v3 的旧锚点问法）。

**产品一句话定义**：
> 追·光 = 一个**实时变化的地理小社区**——在对的时间点，用"此刻此地正好有人/有事值得"，把你从抖音 feed 流里拽出来："这地方现在挺好玩，想去吗？"

两个必须同时成立的能力：
- **地理锚定的即时发现**：全国任意点，刷到"周遭的人此刻发的真实内容"（自带定位）。
- **时机判断（差异化锋刃）**：不是泛泛"附近的帖子"（那是抖音同城页已有的），而是"**此时此地正好值得**"——用天时/光线/热度这类实时信号，把海量 UGC 过滤成"此刻的高光时刻"。晚霞是这个能力的**一种实例**，不是产品主体。

## 3. 三大战略赌注与分支

### 赌注一：全国化怎么落（不靠人工穷举）
- **靠 UGC 自带定位天然覆盖**：附近的人发的内容本身带经纬度，覆盖到哪产品到哪，不靠人工穷举全国机位库。
- **底层已就绪**：地图 / 天气（Open-Meteo）/ 太阳几何（SunCalc）/ 步行路由（OSRM）**全部坐标无关、全国可用**（7.18 侦察实证）。
- **要拆的三层焊死**：① `lib/poi.js` 深圳/上海/LA 机位库常量 + 静默回落上海；② 晚霞评分引擎 `light_engine.js` 的 `f_sun` 因子内在耦合日落；③ 场景枚举 4 值锁死（`CLAUDE.md:70` + 双 validator）。深圳还焊进主键前缀（`szw-*`），全国化须重设 id 方案。
- **数据模型天生就绪**：`photos.v1.schema.json` 早已支持任意经纬度 + nullable `spot_id` 自由散点。

### 赌注二：demo 密度是"条件题"，不是"死结"（枢纽 = 7.24 探针）
全国实时社区要靠密度才成立，但 demo 阶段全国任意点周遭都是空的。**负责人点破关键**：附近视频**自带定位**，若平台把"附近/同城地理内容"开放给我们，真实 UGC 密度就是白来的，假数据能大幅减量。**但这挂在 7.24 平台测绘**（HERMES-04 #13）：

- **分支 A（平台开放附近地理内容）**：产品直接读真实抖音附近内容，种子数据仅少量兜底 → "全国真实密度"天然成立 = 最强演示。
- **分支 B（读不到）**：选**单城造密度**（深圳/上海）真实 seed UGC，叙事讲全国、现场演一城的真密度。

**两条腿都预备，不赌单一分支。** Gate 1 前按 7.24 探针结果二选一定档。

### 赌注三：招牌＝2D 实时社区，GL 3D 作差异化上探（🔻7.19 修正）
**招牌关键路径＝HERMES-10 的 2D Leaflet 实时社区（含★实时冒泡）。** 7.19 Campus 实录证明"地图效果"纯 2D 即 100% 兑现（[campus-teardown.md](campus-teardown.md) §4），2D 版本身就是完整的 Campus 级招牌——招牌下限被这份实录抬高，不再赌 GL。
**GL 3D 光影地图＝差异化上探（HERMES-07/11，🔻P1）**：负责人 7.19 定"GL 已近无问题，楼群消失根因是我们中间叠加的渲染工作，解法＝剥离附加渲染回原生 GL 3D 模型（做减法），非 recovery 攻坚"，并主动降低 GL 差异化优先级。**GL 稳了就加（3D 光影是 Campus 没有的锋刃）、不稳也不塌招牌。**

> **序的修订史**：v3 D-e"纯 2D 先行" → 7.18 v4 曾改"GL 优先 + 2D 保底" → **7.19 定稿：2D 招牌先行（关键路径）+ GL 上探并行（做减法回原生模型）**。
