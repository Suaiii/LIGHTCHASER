## 1｜情报固化：7.23 业务分享要点（含对我们的直接含义）

### 1a. 官方产品思路（AI 兴趣卡 = 赛道三的"标准答案样例"）

| 官方要点 | 原话/事实 | 对追·光的含义 |
|---|---|---|
| 用户痛点 | 个性化不足／信息碎片化／**缺少主动服务（"信息主动找人"）** | 追·光钩子卡=「今晚值不值得出门」主动找人，痛点对表成立 |
| 预期定义 | **「划到一个懂我的瞬间」**；反例=四条内容的无脑聚合 | 与我们第一性同句式；卡必须是"整合出的结论"不是"信息罗列" |
| 试点选择 | 玄学/体育/理财 三垂类；**纯内容分发 vs 轻互动**两形态 | 官方推荐范围表含**生活方式（出行地盲选/本地宝藏推荐）**与**旅游文旅**——追·光赛道合法性被白纸黑字背书 |
| 耗时纪律 | **兴趣卡 pass 掉实时生成，选择离线生成**；"越靠近 feed 消费链路，越要优先考虑耗时、稳定性和降级方案" | 我们 sun_events 450 条预计算 + spots/photos 种子 = 同构打法；**叙事直接引用这条** |
| 工作流选型 | 一期 workflow（规则分发）；agent 理想但 token/时延不可行 | 光线引擎=确定性规则评分，**可解释可复算**，正中官方"一期该用规则"的判断 |
| 交互纪律 | **feed 卡上交互一期仅有点击**；"上下左右滑动和抖音 feed 已有行为冲突" | 卡上不做任何滑动；右滑类交互只能进小程序落地页内 |
| 评测机制 | 数据指标（业务/护栏/终极）+ 内容指标（**安全底线/通用效果[个性化匹配度+逻辑严谨]/垂类专业性**）；人审起步、固定评测集、SOP、数据反哺 | 我们已有的 AGENT_03 盲测（C1 8/10、幻觉 0/40）+ C6 回测 + HERMES-08 历史回测 = **正好是官方要的"评测机制"证据链**，路演按此框架讲 |

### 1b. 官方选题方法论（世界杯五问）→ 追·光五问对表

官方拆解赛道名：AI=更优解法／刷到=被动消费无预期低门槛／懂你=垂直兴趣+全民热点／瞬间=**第一眼体验、3s 定生死**。其世界杯案例的五问，追·光逐问有同构答案：

| 五问 | 世界杯的答案 | 追·光的答案 |
|---|---|---|
| ①信息单元 | 单场比赛（完整/时效明确/有悬念） | **「今晚这场日落」**——每天恰好一场，完整（时间窗+机位+概率）、时效明确（错过即无）、天然悬念（烧不烧天） |
| ②用户分层 | 内容统一，分发千人千面（垂直推主队、泛推 Top 队） | 内容统一=今晚烧天概率；分发差异=摄影用户推机位/参数/黄金窗，泛用户推"下班顺路去哪看" |
| ③形式 | 强竞猜属性→**轻互动**承接（纯信息看完即走） | 晚霞预测天然是竞猜：**AI 报概率，用户押"烧/不烧"，当晚天空开奖**——比世界杯还快的开奖周期（当天） |
| ④结构 | 首卡竞猜抓停留→后卡信息补充延展 | 首卡=竞猜卡抓停留→点击进小程序=地图社区（哪里看+附近的人刚拍到什么）做延展 |
| ⑤AI 角色 | 兴趣识别/预测判断/信息整合/内容生成 | 兴趣识别=城市+摄影/出行兴趣；**预测判断=光线引擎评分（确定性、可解释，优于黑盒）**；信息整合=对谈站 18 条摄影者语录作"作者观点"；内容生成=AGENT_03 文案引擎 |

### 1c. 平台创作链路（教程实锤，取代此前推测）

- 入口：小程序 Tab → 描述需求 → **选"自定义 feed 卡"（AI 内容卡）**→ Vibecoding 生成 → Web 预览 + **抖音 App 扫码真机预览**（需最新版抖音）。
- 六通道全部实锤且有操作路径：Skills（数百预置+自建）/工具/@生成模型/知识库/**数据库（对话建表 + JSON 附件导入 + 单条插入）**/上传文件（文件图片视频）/**Figma 导入（官方教程专节）**。R0 资产轮打法与 first_prompt v1.2 完全成立。
- **模型管理**：平台可切换生成模型，官方原话"建议使用 GPT5.5 / GLM5.2 等，生成效果更优"——vibecoding 效果差时先换模型再改提示词。
- **扫码授权**：扫码登录抖音账号可取真实用户数据（教程例：查当前用户星座做个性化）——**#13"附近内容/用户数据"探针的官方入口**；教程明说"有什么开放能力/用户数据可用，直接问平台 AI 对话"。
- 协作：仅创建者可编辑发布；飞书邮箱加共享查看；**评委随时可访问任一项目**。

### 1d. 创作规范红线（审核向，全部写进任务书）

- **标题 ≤10 字**，必须清晰描述卡片功能（不可宽泛）；主**行动按钮文案 ≤5 字**，点明下一步动作；固定"AI 生成"标签不可去。
- 卡上交互**仅点击**；卡与落地页关键要素必须一致契合（点卡进小程序落地页链路必须可用）。
- 背景不得过浅/过深/模糊；**性能红线**：加载慢/空白/裂图/只出框架=审核失败项。
- 无授权不得用版权内容（对谈站素材授权确认前不得上卡——与 F6 同向）。
- 提交：**1 队 1 作品**；发布配置=小程序名称+图标+应用场景（抖音 Feed/侧边栏搜索）+**运营人信息（队长姓名/身份证/手机号）**→ 审核 → 链接填飞书表格。**审核有周期且时长未知 = 新的日历硬约束**。

## 2｜方向判定：两轴不变，feed 卡升级为竞猜卡

**方向对不对：对，且被加强。** 两轴（①钩子 feed 卡 ②地图实时社区）与官方"首卡抓停留→落地页延展"结构完全同构；"生活方式/旅游文旅"在官方推荐选题表内；离线预计算、规则评分、评测链三件我们已有的资产恰好是官方方法论逐条要求的东西。**不需要转向，需要的是把已有资产按官方语言重新装配。**

**★P-1（待负责人拍板）：钩子卡从"纯内容"升级为「今晚烧天竞猜卡」。**
- 卡面：标题（≤10 字，如「今晚晚霞预报」）+ 城市/机位背景图 + **AI 预测概率**（光线引擎评分→烧天概率+一句为什么）+ **两个点击投票位（会烧/不烧）** + 行动按钮 ≤5 字（如「去哪看」）。
- 闭环：今晚实际天空=开奖 → 明日回访卡（"昨晚你押对了，今晚 XX% 再战？"）——**世界杯竞猜的同构物，但开奖周期只有几小时**，是全场少有的"天然每日留存钩子"。
- 成本：光线引擎/文案引擎/数据全部已有，增量只是卡面交互与开奖文案；纯内容版保留为降级档。
- 依据：官方问题3明说"纯信息容易看完即走…轻互动更容易抓停留"；投票按钮=点击，合规。

**★P-2（待拍板）：路演叙事框架切换为评委自己的方法论**——痛点四问/五问对表/离线生成纪律/评测机制（盲测+回测+护栏），用官方词汇（信息单元、用户分层、轻互动、垂类专业性）讲我们的东西。AGENT_08 叙事稿按此重构。
