## 1. 第一性检验（赛题锚点）

锚点原文："**用户在刷到的一瞬间，是否就能被打动、被满足，并自然产生一次互动或使用？**"（体验完整性 30% 最重）

三板块构成一条**行动漏斗**，理想终态是回流成环（回流环见下方诚实边界）：

```
刷到（板块一：0.5s 读到分）
  → 出门（板块二：地图上"刚有人在这里拍到了这个"——社会证明比评分更打动人）
    → 拍到（板块三：AI 帮你拍出来）
      ┈┈▶（回流环，待板块三对齐后排期）成片带位置回流 → 成为别人地图上的气泡
```

- **被打动**：真人刚拍的真照片 > 任何评分数字。气泡层把"值得去"从算法断言升级为社会证明。
- **被满足**：看到照片=看到目的地=一键金线路由，行动路径更短（恰到好处四问之③）。
- **一次互动**：点开气泡看照片、「去这里」一键触发路由——锚点后半句的直接答案。看见附近的人的作品=轻社交第一步；**真交友能力（关注/私信/约拍）属平台版 roadmap，本期不做**（HERMES-10 全 DoD 无交友功能，路演口径同此档，不超配承诺）。

**闭环诚实边界**：回流环最后一环（发布→带位置回流→成为气泡）当前三步全缺（成片无坐标/无持久层/无气泡消费，见 §7 缺口 4），且依赖尚无任务书的板块三对齐。HERMES-10 phase 2 可选做一个演示态最小回流（复用板块三现成发布 CustomEvent → 本地写入 photos → 气泡即时浮现）使"环"以演示态可见；未做则本期按单向漏斗呈现，不拿未排期的环当体验完整性论据。

**风险与对冲**：
- UGC 冷启动 → demo 期用**渐变垫图（标 status=垫图）+ 外联回流的深圳授权照片**播种；**初赛静安寺素材属上海、禁赋深圳坐标上地图**（否则=编造地点，Blocking 级），最多作点开卡交互示意。F6 逐张标 credit/consent/status；
- 视觉预算 → 亮度纪律扩展为**金色路线 > 见光点 > 照片气泡**三级（HERMES-03 红线的延长线，待 D-c 拍板；Leaflet 版无"见光点"元素，取两层口径，完整三层随 HERMES-11 GL 移植）；
- 隐私 → 借 Instagram Map 模式：默认只共享"我在某机位拍了照"的**事件位置**而非实时人身位置，看与被看解耦（不共享也能浏览）；demo 数据全部授权样张；
- 平台可行性 → 平台地图组件能否承载气泡层未测 → HERMES-04 7.24 测绘扩项，R5 三档话术同步扩展。

## 3. 竞品参照（研究编队 7.15 实证）

**Campus（负责人点名）**：确认存在——「Campus - 标记我的校园」，开若图科技（上海）出品，2026-05 v2.0"首页地图焕新"、现每周迭代。地图气泡+弹幕实锤（App Store 用户评论原话："地图气泡和弹幕都挺有意思的，整体的感觉很轻盈"）；气泡内容不止照片（照片/声音/心情）；隐私标签收集精确位置+照片，与位置-照片社区形态一致。⚠️ **"上海交大校友开发"一说中英文约 10 轮检索无任何来源支持**（工商信息未被索引），对外材料勿当事实引用。气泡具体视觉形态/聚合规则公开网页无记载，需真机或小红书/B站实录确认——挂人工池。

**可直接采用的交互范式**（12 条全文见研究档案，这里列入选 6 条）：

| 范式 | 来源 | 用法 |
|---|---|---|
| 缩略图聚合气泡：照片当封面+数字角标，缩放重聚合 | Apple 照片·地点 | 气泡骨架方案；晚霞照片色彩强，比圆点传达力强一个量级 |
| 尺寸编码热度：张数越多气泡越大（3 档 48/64/80px） | 聚合规范/supercluster | 扫一眼知道今晚去哪 |
| 时间筛选=胶囊切换+全量重聚合；"一天内"默认高亮 | Snap Map/IG Map 的 24h TTL 变体 | 直接对应负责人"一天内/一周内" |
| 点开不跳页：半屏 bottom sheet，地图平移保持该点可见 | 小红书地图 | 小程序单页架构最优解；SpotDetail 改造落点 |
| 同点多照 spiderfy 扇形散开 | OverlappingMarkerSpiderfier | 好机位天然聚集；散开一圈晚霞缩略图=demo wow 时刻（可选加分项） |
| 分级隐私：事件位置≠人身位置，可看不可被看 | Instagram Map（2025.8） | 交友能力的隐私模板，规避 LBS 社交最大争议 |

**反例**：Google Maps 照片强制挂 POI——追·光必须支持非 POI 自由散点（晚霞发生在任意天桥/江边/楼顶），官方机位可另设"照片墙"承载历史最佳。
