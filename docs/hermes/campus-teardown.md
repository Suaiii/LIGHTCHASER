## 0. 一句话结论（给赶时间的人）

Campus 的「地图位置效果」＝**一张普通 2D 矢量地图上，把附近的人刚发的真实内容（照片/视频/文字便签）当作气泡，锚定在真实 POI 上；配一个随手机朝向转动的蓝色光锥定位标；点气泡→半屏帖子详情（作者/地点·时间/图集/点赞评论）**。

**最重要的一条战略情报**：**Campus 的地图是纯 2D 矢量瓦片（高德/腾讯风格），不是 3D GL 建筑地图。** 它的"活着的社区感"全部来自 ①内容气泡锚定 ②朝向光锥 ③地图轻微倾斜/旋转 —— **与 3D 楼群无关**。这对我们的 **P-6（GL 优先 vs 2D 保底）** 是重大减压：**轴二的"Campus 感"在 2D Leaflet 上就能 100% 兑现，GL 3D 是差异化加分项，不是"Campus 感"的前置条件。**

| **相机打卡（FAB）** | 发布：滤镜（经典/黑体/像素/手写/DASH/GRID）+ 模式（语音/拍照/文字），带地点戳（"学生宿舍西32号楼"） | `camera-capture.jpg` |

## 2. 地图 tab 逐元素拆解（抄板清单）

对照 `map-bubbles-A.png`（含文字便签气泡）与 `map-bubbles-B.png`（多张照片气泡 + 美食帖）：

### 2.1 底图
- **2D 矢量瓦片**，非卫星非 3D。配色：低饱和米白路网 + 浅绿地块/校园 + 浅蓝水系。**极浅、克制**，让内容气泡成为视觉主角（我们 `docs/tokens.md` 的暗色系要另行适配——Campus 是亮色底）。
- **地图轻微旋转**（非正北朝上，随朝向转），四周有**虚线校园边界**（灰色 dash）——给"这是一个圈定的小社区"的心理边界感。**轴二全国化后这条边界怎么处理是一个设计问题**（见 §5 差异）。
- 顶部 **"Map" 大标题 + 地点下拉**（"上海交通大学(闵行校区) ▾"）——可切区域。

### 2.2 内容气泡（核心，三种形态）
1. **照片/视频气泡**：略微**倾斜**的白边卡片（拍立得质感，阴影微投），缩略图封面。多张成组时叠放。锚在 POI 附近，POI 名带 emoji 图标（📍气膜体育中心 / 🍴第二餐饮大楼 / 🍸包玉刚图书馆 / 🏀篮球场）。
2. **文字便签气泡**：**便利贴色块**（桃色 / 鹅黄），圆角，手写体感，投影。内容是真人一句话——"有擅长SPSS结构方程模型的朋友吗？有偿求帮忙" / "东转旁边那么多人排队是在干嘛"。**这类"求助/闲聊/问路"便签是社区活人味的关键**，比纯照片更像"此刻有人在这"。
3. **带贴纸的图文卡**：照片上叠 emoji 贴纸/标签（"#Daily food 🤤" / "#Yummy"）——UGC 自带的表达层。

> **我们已有的对应件**：`subpanels.jsx` 的 `NoteCard`（照片卡带评分徽章/作者/视频角标，:624-751）＝照片气泡本体的现成改造起点。**文字便签气泡是新形态**——现原型没有，需新增（轻量，纯 CSS 卡片）。HERMES-10 §2.3 气泡视觉规格应补入"文字便签"这一路。

### 2.3 定位标（signature 细节，别漏）
- **蓝色圆点 + 朝向光锥**（fan/cone），锥体指向手机朝向，随转动扫动。见 `map-heading-cone.jpg`。这是"我在场、社区活着"的最强低成本信号，苹果地图同款。
- **成本极低、观感极高**——2D 上一个 CSS/canvas 扇形即可。**强烈建议轴二保留**（现原型 Leaflet marker 基建 `L.divIcon` 已在 `subpanels.jsx:232`，加朝向锥是小改）。

### 2.4 交互（从视频）
- **缩放**：捏合缩放，缩小时气泡应聚合（视频里不同 zoom 档露出的是底图 label 疏密变化；聚合规则 Campus 视频未明确演示单点→簇，我们按 HERMES-10 §2.3 第 2 节自定）。
- **点气泡 → 帖子详情**（`post-detail.jpg`）：作者头像+名、地点·时间、图集左右轮播、底部评论框、♥赞/评论数。**这是半屏还是全屏？** Campus 实录是**近全屏详情页**（顶部返回箭头+分享）。我们 HERMES-10 定的是**半屏 bottom-sheet 保持地图可见**——**这是有意的差异（我们更想让人留在地图上），不是抄漏**，见 §5。

## 4. 对 P-6（GL vs 2D）的直接结论

**Campus 用纯 2D 就做出了我们想要的全部"实时地理小社区"观感。** 因此：
- **轴二的 MVP / demo 保底 = 2D Leaflet 气泡层**（HERMES-10 phase 2）——足以 100% 复刻"地图位置效果"，Gate 1 可交付。**这是拿得稳的招牌。**
- **GL 3D 光影地图（HERMES-07/11）= 差异化上探**——3D 楼群 + 晚霞光线扫过是 Campus **没有**的、我们的锋刃；但它是"锦上添花"，**不是"Campus 感"的前置**。若 GL 到 Gate 1 仍不稳，2D 版独立成立、招牌不塌。
- **建议维持 P-6 现状（GL 优先 + 2D 保底并行），但风险叙事更新为**："即便 GL 完全失败，2D 版就是一个完整的 Campus 级招牌"——**赌注下限被这份实录抬高了。**

## 5. 我们**有意不抄** / 必须改的地方（别照搬踩坑）

1. **全国化 vs 校园边界**：Campus 是**单校园闭域**（虚线圈住交大闵行），内容天然稠密。我们要全国 → **没有那圈边界的天然密度**。这正是 **demo 密度双分支（P-2）** 要解的题——Campus 的"稠密"是校园封闭换来的，我们换不来，只能靠 ①平台开放附近内容(分支A) 或 ②单城造密度演示(分支B)。**抄它的形，但它的密度前提我们没有**，别被截图的热闹误导以为密度免费。
2. **详情页：全屏 → 半屏**。Campus 点开是近全屏详情；轴二有意做**半屏 bottom-sheet 保持地图可见**（HERMES-10 §2.3 第4节）——因为我们的核心价值是"把你留在'附近正在发生什么'的地图上"，不是逐帖深读。**这是差异不是遗漏。**
3. **晚霞/光线锋刃**：Campus **完全没有时间/天时维度**——它是"全天同质的校园墙"。我们的差异化 = **用天时/光线实时信号把 UGC 过滤成"此刻此地的高光"**（P-1 晚霞降为锋刃）。抄 Campus 的地图形态，叠我们独有的"此刻值得"时间轴（今天/本周胶囊 + 晚霞高光态）。
4. **相机不抄**（P-3）：Campus 的拍照打卡+滤镜是它的发布入口；我们连不到抖音内容生产界面，**发布回流靠平台侧能力（7.24 HERMES-04 测绘）**，不自建相机。
5. **商业**：Campus 是纯校园社交、无商业层——正好印证 v4 §5"本期产品做内容/流量/本地发现价值、商业留作 roadmap"的取舍与 Campus 抄板不冲突。

## 6. 事实澄清（更新旧存疑）

- ✅ **实锤**：Campus 是**校园定位社交 App**，本机定位在**上海交通大学(闵行校区)**，地图/广场/相机三视图 + 帖子详情结构如上，气泡+便签+朝向锥均真实存在。取代此前"公开网页查不到气泡视觉"的存疑。
- ⚠️ **仍存疑、勿对外引用**："开若图科技·上海"主体、"**交大校友**创办"说法**查无一手实据**——实录只证明 App 面向交大校园使用，**不证明创始人身份**。路演/对外叙事**不得**引用校友说法。
- 📌 竞品定位差异（对评委可讲）：Campus＝单校园闭域社交墙（无时间维度、无商业）；追·光＝**全国实时地理社区 + 天时高光过滤 + 抖音 feed 流钩子**。抄其地图形态，走其没走的三条路。
