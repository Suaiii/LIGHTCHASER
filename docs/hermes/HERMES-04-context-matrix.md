## 0. 为什么做（对赛题的回答）

赛题是"刷到**懂你**的瞬间"。懂不懂你，取决于我们从抖音平台**实际能拿到什么上下文**——位置拿不到，"步行 16 分钟"就是编的；时间上下文拿不到，"距峰值 38 分钟"就是猜的。这是"恰到好处"四问的第一问，**所有个性化承诺的地基**。细则只给了模糊说法（可用"抖音数据 API"、有「扫码授权」、举例"真实用户星座数据"），字段级可得性必须 7.24 进平台实测。

## 1. 背景（自包含）

- AGENT_06（`Thoughts/AGENT_06_平台测绘.md`）已排 7.24 十二问测绘。其中问 2（能否取用户定位）、问 8（扫码授权/数据 API 能拿哪些真实用户数据）与本任务相关——但**停在"能不能"层面，没拆到字段级**。本任务是问 2/问 8 的深挖包，不替代十二问其余部分。
- 已知线索（来自赛道细则截图，`docs/赛道细则/image/`）：平台内可"查询可用资料——有什么抖音开放能力/用户数据可用"；「抖音扫码授权」可"查看用户账号真实预览状态或获取相关用户数据"；官方例证是"真实用户星座数据"。
- 产品需要的上下文优先级（P0 缺了产品不成立 / P1 增强 / P2 锦上添花）：
  - **P0 位置**：精度（市/区/百米级？）、授权路径（弹窗文案能否自定义？）、拒绝后能否退化到"选择城市"
  - **P0 时间**：服务端/客户端时间可得性（判断"距日落还有多久"）
  - **P1 信息流上下文**：能否知道用户是从 feed 卡点进来的、刷到的时间段
  - **P1 用户画像**：星座之外还有什么（年龄段？兴趣标签？关注内容类目？）——决定"懂你"文案的个性化深度
  - **P2 社交**：能否知道好友/附近的人（对应地图上"附近追光者"是否能做成真的）

## 2. 目标

产出 `agents_output/06/context_matrix.md`：一张**字段级矩阵**，每行一个上下文字段，列固定为：

| 字段 | 可得性(是/否/条件) | 精度/粒度 | 授权成本(免/弹窗/扫码) | 实测证据(截图号/操作路径) | 缺失时降级方案 | 对产品的影响面 |

**降级方案列是灵魂**：每个 P0/P1 字段必须写清"拿不到怎么办"（例：位置拿不到 → 卡片首屏改为"选择你的城市"一次性选择，缓存进平台数据库表）。这一列直接喂 AGENT_05 需求包的边界态设计。

**不做什么**：不评测平台组件/动效/审核（那是 AGENT_06 十二问其余部分）；不做隐私合规法律分析（标注"待核"即可）。
