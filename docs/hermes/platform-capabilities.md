> 来源：负责人 2026-07-14 提供的平台官方文档截图 3 张（`agents_output/05/inputs/platform-doc-*.png`）。
> 本文件是 7.24 前唯一的"平台能做什么"权威依据；**存在性已确认，边界数值（容量/格式/还原度）全部待 7.24 实弹测**（HERMES-04 §4b）。7.24 后由测绘结论回填更新本文件。

## 七项功能（官方原意提炼）

| # | 功能 | 官方说明要点 |
|---|---|---|
| 1 | **扩展功能** | 可手动为模型添加 Skills／工具／生成式模型／知识库四类扩展 |
| 1a | Skills | 平台资源库**预置数百种**可选；不满足可**自建**——把自定义执行逻辑、提示词、工具调用、流程与校验规则封装成可复用组件，被 AI 无缝调用。官方示例：`frontend-design` skill 提升前端设计质感 |
| 1b | 工具 | 为智能体添加工具，支持配置参数信息 & 卡片 |
| 1c | 生成式模型 | 编辑器里 **@模型** 即可让 AI 调用文本/图片生成（官方例：@Doubao-seed-2.1-pro 回复星座问题）——**图片生成可 @** |
| 1d | 知识库 | 引用抖音现成 or **自助创建**；AI 遇陌生问题从挂载知识库检索、整合生成回答（适合长文本语料） |
| 2 | **数据库** | 对话建表（话术：表名+包含什么数据+获取和存储逻辑）；写入三方式：**① 附件上传任意文件类型（如 JSON）导入项目文件** ② 自然语言"使用该 xxx 数据构建线上数据库初始数据" ③ 手动单条插入。左侧项目管理/右上角 icon 可查看表结构与数据 |
| 3 | **上传文件** | 上传按钮直接传模型要用的内容，**支持文件／图片／视频** |
| 4 | **Figma 导入** | 可导入**高保真 Figma 设计稿链接**，让模型还原卡片视觉效果（平台内有教程） |
| 5 | **模型管理** | 可切换生成模型；默认平台自动使用最佳模型 |
| 6 | **扫码授权** | 抖音扫码登录 → 查看该账号**真实预览状态**／获取相关用户数据 |
| 7 | **协作权限** | **仅创建者可对话、编辑、发布**；「权限管理」输入队员飞书邮箱 → 共享查看/调试。**大赛评委随时可访问任一项目，不受权限约束** |

## 对我们的决策级影响

1. **战法转向"资产先行 + 对话编排"**（负责人 7.14 拍板）：纯 prompt 让平台一口气搭架子不现实；保真性靠六条资产通道——数据库 JSON 导入（数据）、Figma 链接（视觉）、上传图片/视频（参考与动效意图）、自建 Skill（设计系统规则常驻）、知识库（长文本语料）、@图片生成（素材兜底）。备料=HERMES-09，实测=HERMES-04 §4b。
2. **单驾驶员纪律**：仅创建者可对话/编辑/发布 → 7.24 前定唯一驾驶员（谁建主项目谁贴 prompt），其余队员飞书邮箱加查看/调试权。
3. **评委随访纪律**：评委随时能打开我们的项目 → 线上主项目**任何时刻保持可演示状态**，大改前先确认稳定版可回退；实验一律进 `sandbox-` 前缀项目。
4. **扫码授权 = 字段级测绘的主通道**（HERMES-04 执行手册已内建）。
5. **数据库 vs 知识库分工**：结构化可查询（机位/太阳事件/天气/评分）→ 数据库表；长文本（攻略描述、写作规则、few-shot 语料）→ 知识库。
6. **feed 卡素材兜底链**成立：授权样张 > 7.28 自摄 > @图片生成（标注 AI 生成）——开发期垫图用 @图片生成，平台内零成本。

## 7.24 必须实测的边界（喂 HERMES-04 §4b）

附件上传大小/行数上限 ｜ Figma 还原丢什么 ｜ 视频参考模型是否真消化 ｜ 自建 Skill 格式与"每轮是否生效" ｜ @图片生成质感 ｜ feed 卡组件本身能否带动效。
