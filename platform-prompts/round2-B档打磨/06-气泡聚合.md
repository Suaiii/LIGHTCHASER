# R2-06 · 照片气泡聚合（苹果相册地图式）

**配套上传**：`materials/gl/bubble_spec.md`（§2 已按 0726 真机订正）+ `materials/motion/media/video-04-cluster-zoom.webm`（**真交互录屏 18s：缩小合簇→放大散簇→点击展开**，让它照着做，比文字管用）。

> 前置：R2-01 气泡观感已过。本条只解决"缩小后一堆原尺寸气泡互相压叠"的观感问题。

## 粘贴给平台 AI（第一段：做聚合）

```
地图上的照片标记要做聚合，规则严格照抄：
1. 地图缩放或移动结束后重新计算：把彼此靠得太近的照片合成一个"聚合标记"。
   判定距离用地面实际距离，不要用屏幕像素距离——地图是斜视角，远处几公里
   在屏幕上只有几像素，用像素会把十几公里外的照片错误合并。
   换算公式：合并距离(米) = 阈值像素 × 40075017 × cos(纬度) / (512 × 2^缩放级别)
   阈值像素：缩放≤12 用 96，13-14 用 72，≥15 用 48。
2. 聚合标记外观：像一叠照片——两张白卡分别左倾 7 度、右倾 5 度垫在底下，
   最上面是代表照片（取最新那张）；左上角橘色 #ff8a3d 圆形数字角标显示张数；
   下方胶囊标签写"N 张照片"。
3. 右上角标必须保留（不许因为聚合就省略）：全是种子数据写"示例 · N 张"，
   含新发布的写"演示 · N 张"。
4. 点击聚合标记：地图放大 1.6 级并居中到该簇，放大后自动散开成单张气泡。
5. 放大回去时聚合要自动解散，缩小时自动合并，不需要用户手动操作。
做完给我截图：缩小状态和放大状态各一张。
```

## 粘贴给平台 AI（第二段：避坑，务必单独发）

```
两个必须避免的实现错误：
1. 标记的入场动画不要直接写在标记元素本身上。如果动画带位移/缩放
   且用了 fill-mode: both，动画结束后的变换会覆盖地图库给该元素的定位变换，
   结果是所有标记叠在地图左上角、完全不在地理位置上。
   正确做法：外层容器只负责定位（不加动画），内层元素只负责动画。
2. 不在可见地面上的照片不要渲染：离屏幕中心超过 60 公里的、
   或投影落在画面最上方 16% 那条地平线带里的，一律不显示——
   否则它们会糊在天边，看起来像"照片飘在天上"。
做完把地图缩到全城截图给我，标记应当分散在各自的真实位置上，不能挤成一堆。
```

## 验收

- [ ] 缩小到全城：标记数明显减少、出现带数字角标的"照片叠"
- [ ] 放大回街区：聚合解散成单张气泡，各自落在真实位置
- [ ] 点聚合标记：放大并散开
- [ ] **标记分散在地图各处，没有任何一堆叠在角落**（这条不过说明踩了第二段的坑 1）
- [ ] "示例/演示"角标在聚合后仍常显（F6 红线）
