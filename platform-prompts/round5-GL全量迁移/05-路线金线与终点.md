# R5-05 · 路线金线与终点标记

**配套上传**：`materials/gl/gl-migration-spec.md` §7 + `materials/gl/screenshots/01-开场-3D楼群与金线.jpg`

> 前置：R5-03 通过。这条金线是"去这里"的视觉承诺，也是整页唯一的亮色主角。

## 粘贴给平台 AI（第一段：三层线）

```
在地图上画一条从当前位置到目标机位的路线，三层叠出来：
1. 辉光层：线宽 16，颜色 #ff8a3d，模糊 8，不透明度 0.5，圆头圆角
2. 芯线层：线宽 4.5，颜色 #ffd49a，压在辉光上面
3. 脉冲层：两个白色圆点，半径 5，模糊 0.35，沿着这条线循环流动，
   两点相位差半圈
路线数据先用一条直线（起点到终点两个坐标）跑通，接真实路网后再替换。

标记两个端点：
- 起点：14px 白色圆点，外面套 3px 半透明白环，带白色外发光
- 终点：16px #ffd49a 圆点带发光，下面挂一个机位名胶囊
  （底 rgba(14,17,26,0.82)，字色 #ffd49a，11px 加粗，圆角胶囊）
```

## 粘贴给平台 AI（第二段：性能，务必单独发）

```
脉冲点的位置更新每 4 帧做一次，不要每帧都更新。
原因：更新地理数据源会强制整张地图重绘，60 帧全速更新等于
地图静止时 GPU 也在满载跑，手机会烫、电量掉得快。
另外加一个闲置慢旋转：无操作时地图方位角每帧转 0.018 度；
用户一触摸立即停，松手 4 秒后恢复。
如果系统开了"减弱动态效果"，脉冲和自转全部关掉。
```

## 粘贴给平台 AI（第三段：开场镜头）

```
页面打开时把镜头调到能看全路线的视角，但缩放级别不许低于 14.65。
原因：长路线（4 公里以上）全览会掉到缩放 12.8 左右，
那个高度上 3D 楼群还没长出来，开场第一眼只有平面剪影，
和"第一眼就是立体楼群"的效果相悖。宁可路线出画一点，也要保住楼。
镜头动画 900 毫秒，pitch 保持 62，bearing 保持太阳方位角减 60 度。
```

## 验收

- [ ] 金线从起点连到机位，有外发光晕
- [ ] 白色脉冲点沿线流动，两点错开
- [ ] 终点有发光圆点 + 机位名胶囊
- [ ] 开场镜头停在 zoom ≥14.65，**能看到立体楼群**
- [ ] 静止 30 秒手机不明显发烫（说明脉冲隔帧生效了）
- [ ] 闲置几秒后地图缓慢自转，触摸立即停
