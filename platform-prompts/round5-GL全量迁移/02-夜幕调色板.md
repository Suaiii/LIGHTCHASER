# R5-02 · 夜幕调色板（把 liberty 压成追·光的夜）

**配套上传**：`materials/gl/gl-migration-spec.md`（§3 是这一步的完整表）+ `materials/gl/screenshots/01-开场-3D楼群与金线.jpg`（成品对照）

> 前置：R5-01 通过。这一步是**观感的一半**——底图不压暗，后面所有橙色元素都浮不起来。

## 粘贴给平台 AI（第一段：确定性调色）

```
把地图样式压成夜幕调。做法是拉下样式 JSON、逐图层改写颜色后再喂给地图。
铁律：每类图层给死一个颜色，不许做任何"把原色调暗/混色"的换算——
通用混色公式会把绿地混成深青、把品红混成紫，我们踩过。

判定用「图层 id + source-layer」一起做正则匹配，按下表给色：
- 背景层 → #141824
- 匹配 water → #17203a
- 匹配 landcover|park|grass|wood|forest|vegetation|golf|cemetery|scrub|meadow → #1a2230
- 匹配 building → #1e2536
- 线图层且匹配 motorway|trunk|primary → #5d6884
- 线图层且属于路网(transportation|road|bridge|tunnel|path|aeroway) → #3b4560
- 其他线图层 → #242d44
- 其他面图层 → #161d2c
- 圆点图层 → #3a4358
- 其余兜底 → #1c2333
- 所有 text-color → #c0c8dd
- 所有 text-halo-color → #0d1017，同时把 text-halo-width 设成 1.4

另外：把样式里原有的所有 fill-extrusion 图层整层删掉，
3D 建筑后面我们自己加一层，两套楼同时存在会互相闪烁。
```

## 粘贴给平台 AI（第二段：标签处理，务必单独发）

```
标签有三个必须处理的细节，每条都对应一个真实的显示故障：
1. 只给「点状」地名标签设 text-pitch-alignment 和 text-rotation-alignment 为 viewport。
   沿路排布的标签（symbol-placement 是 line 或 line-center）绝对不能设——
   设了之后路名的字会沿着路堆叠成乱码。
2. 纯文字的点状图层，字号小于 12 的抬到 12.5；带图标的路牌盾徽不要动。
3. POI/车站类图层（id 或 source-layer 匹配 poi|station|transit|bus|aerodrome|housenum）
   把 minzoom 抬到 15.4（门牌号那类抬到 17），text-padding 设 6，
   有图标的设 text-optional 为 true。否则倾斜视角下标签会和楼穿插堆叠成一团。
```

## 粘贴给平台 AI（第三段：天际光晕）

```
在地图上方叠一层不拦截触摸的渐变：页面顶部 30% 高度，
从颜色 #DE6B48 透明度约 32% 渐变到全透明，方向从上到下。
这层是日落氛围，后面接了太阳计算之后这个颜色会随时刻变，先用这个值。
```

## 验收

- [ ] 整图是深蓝夜幕，不是"变暗的白天图"
- [ ] 绿地是深灰蓝，**没有出现青色/紫色块**（出现即说明它偷偷做了混色换算）
- [ ] 路名清晰可读，**没有沿路堆叠的乱码**
- [ ] 倾斜到 62° 时标签不与地物糊成一团
- [ ] 顶部有橙色天际渐变，且不影响拖动
