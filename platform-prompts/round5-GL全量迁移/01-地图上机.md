# R5-01 · 地图上机（maplibre + 瓦片 + 相机）

**配套上传**：`materials/gl/source/light-map-gl.jsx`（能传就先传，胜过任何转述）+ `materials/gl/gl-migration-spec.md`

> 这一步只解决"地图能不能出来"。出不来，后面五步全废，直接转 B 档。

## 粘贴给平台 AI（第一段：把地图跑起来）

```
接入开源地图库 maplibre-gl（BSD-3 许可，可商用）做一个全屏地图页：
- 样式源：https://tiles.openfreemap.org/styles/liberty
- 中心 [113.9819, 22.5238]（深圳湾），zoom 14.65
- 相机 pitch 62 度，maxPitch 70，允许双指旋转和俯仰
- 页面底色 #141824（瓦片没加载出来时不要露白）
- 角落显示当前帧率
如果项目机制不支持 npm 依赖，就用你可行的方式引入（CDN 或整段内联），
并明确告诉我你用了哪种方式。
真机能看到街道瓦片即成功。
```

## 粘贴给平台 AI（第二段：署名与失败兜底，务必单独发）

```
两条硬要求：
1. 地图必须保留 OpenStreetMap 数据署名（maplibre 的 attributionControl，
   compact 模式即可）。这是 ODbL 许可的强制要求，不许为了美观去掉。
2. 加一个 9 秒超时：如果样式源加载不出来（断网/域名不可达），
   自动切到备用样式 https://basemaps.cartocdn.com/gl/dark-matter-gl-style/style.json，
   并在角落显示"备用底图"字样。两个都失败就显示纯色底 + 一行提示，不要白屏。
```

## 验收

- [ ] 真机看到街道瓦片（不是灰格子/白屏）
- [ ] 拖动、缩放、双指旋转俯仰都流畅
- [ ] pitch 62° 下有明显的"往前看"透视感
- [ ] OSM 署名可见
- [ ] FPS 显示 ≥ 30

## 失败分支

- **瓦片白屏但地图框架起来了** → 域名问题：①换 cartocdn 备用源 ②问平台要网络白名单配置。两条都死 → B 档。
- **maplibre 引不进** → 问它内置地图组件方案，直接转 B 档（`bubble_spec.md §8` 有 B 档完整规格）。
