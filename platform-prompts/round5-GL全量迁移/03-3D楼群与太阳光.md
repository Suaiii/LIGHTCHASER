## 粘贴给平台 AI（第一段：立体楼群 + 定向光）

```
给地图加 3D 建筑层，参数严格照抄：
图层类型 fill-extrusion，数据源 openmaptiles 的 building 图层，minzoom 12.5
- 颜色 #1d2436
- 高度取瓦片属性 render_height，取不到就用 12
- 底面高度取 render_min_height，取不到就用 0
- 不透明度 0.62，开启 vertical-gradient（顶亮底暗）
- 不透明度过渡时长设 0（缩放本身就是连续量，不要再叠加滞后动画）

同时打开地图的光照：
anchor 用 "map"（让光随地图旋转保持地理方向正确），颜色 #ffe3c4，强度 0.55，
position 三个分量分别是 [1.5, 太阳方位角, min(88, 90 - 太阳高度角)]。
太阳方位角先写死 283 度、高度角 7 度，下一段接真实计算。

注意光色用的是暖白不是橙色——彩色光和底色相乘会产生不可控的青紫怪块，
主题橙色交给天际渐变去承担。
```

## 粘贴给平台 AI（第二段：接真实太阳）

```
我上传了 suncalc.js（BSD-2，约 300 行，纯几何计算，不联网）。
把它整段内联进项目，然后：
1. 用 SunCalc.getPosition(当前时间, 纬度, 经度) 算太阳位置；
   方位角换算成度数是 (azimuth * 180 / π + 180 + 360) % 360，
   高度角是 altitude * 180 / π。
2. 地图初始 bearing 设成「太阳方位角 减 60 度」——这样受光面正对镜头。
3. 用高度角查一张颜色表算出当前的"光色"，用它替换天际渐变的颜色。
   表（高度角 → 颜色，中间线性插值）：
   -6°→#5A3870, 0°→#8A4068, 3°→#C84858, 8°→#DE6B48,
   16°→#E0A060, 30°→#EBC28E, 55°→#F2E2C4
   我上传的 zg-sun-helpers.js 里有现成的插值函数，直接用。
4. 如果 suncalc 内联失败，就改读我提供的预计算表 sun_events.v1.json，
   不许自己编方位角数值。
```

## 粘贴给平台 AI（第三段：LOD 生长动画）

```
缩放时楼不要硬切显隐——突然蒸发看起来像故障。
做法：zoom 从 14.6 到 15.4 之间算一个 0 到 1 的进度，
再过一遍平滑曲线 t*t*(3-2t)，用它控制楼的高度比例。
拉近时楼从地面长出来（约 750 毫秒），拉远时缩回地里（约 480 毫秒）。
动画进度用「绝对时间轴」算（记录起始时刻，每帧按经过时间插值），
不要用逐帧累加——低帧率设备上逐帧累加会让动画变慢。
```

## ⚠️ 第四段：Three.js 真光影（可选，A 档；做不动立刻停）

只有在前三段全绿、且平台允许引入 three.js 时才发这一段。
**判定：出现残影/乱码或 FPS<25，立即回退到只有 fill-extrusion 的版本。**

```
在地图上再加一个 three.js 的自定义 3D 图层，和地图共享同一个 WebGL 上下文。
这一层接管近景建筑，给每个立面真实的受光/背光和楼间投影。
必须遵守的七条（每条都对应一个我们真机踩过的故障）：
1. 每帧渲染前调用 renderer.resetState()，否则会出现帧级乱码残影。
2. 建筑合批后的 mesh 设 frustumCulled = false，
   否则特定角度整片楼会被误剔除而消失。
3. 分帧构建，每帧最多处理 40 栋；新的重建请求要能作废进行中的旧构建。
4. 先建好新的再替换旧的；构建结果为空时保留旧楼——宁可显示旧数据也不要空场。
5. 阴影贴图关掉自动更新，只在楼长到满高时手动烘一次。
6. 立面不要接收阴影（receiveShadow = false），只投射阴影；
   阴影偏置设 normalBias 3、bias -0.0002。日落时太阳只有 7 度高，
   掠射角下立面自阴影会出现白噪竖纹，这是唯一解。
7. 建筑材质 color #333c54，metalness 0.5，roughness 0.55，
   透明度 0.68，depthWrite 保持 true。楼是配角，不许抢戏。
做完告诉我 FPS 和有没有出现闪烁残影。
```

## 失败分支

- **帧率崩** → 依次降载：①降低 fill-extrusion 不透明度 ②过滤掉低矮建筑 ③pitch 降到 45°。仍崩 → 退 2D 暗色地图（调色板保留，去掉 extrusion），气泡照上，观感仍成立。
- **瓦片没有 height 属性** → 让它查该样式源 building 图层的实际属性名；确实没有 → 同上退 2D。
- **Three 层出问题** → 立即回退到第一段版本，**A− 已经成立，不要为 A 赌掉 A−**。
