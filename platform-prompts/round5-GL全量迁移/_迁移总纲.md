## 先定"成功"是什么（四档）

| 档 | 内容 | 掉档条件 |
|---|---|---|
| **A** | + Three 自定义层：每面真实受光/背光 + 楼间投影 | 残影或 FPS<25 → A− |
| **A−｜招牌线** | MapLibre + fill-extrusion 立体楼 + 夜幕调 + 太阳定向光 + 金线 + 气泡 | 楼立不起来 → B |
| **B** | 平台内置地图 + 光位罗盘 + 2D 照片点 | 地图组件都没有 → C |
| **C** | 录屏内嵌 + 照片时间流 | —— |

**目标是 A−，A 是加分。** A 档的风险全在共享 WebGL 上下文（spec §9 坑 4–10）。
A− 已经能给出完整观感：深蓝夜幕 + 立体楼群 + 橙色天际 + 金线 + 照片气泡。**别为了 A 赌掉 A−。**

## 一句话打法

**能传源码就先传源码。** `materials/gl/source/light-map-gl.jsx` 1038 行里，注释写满了每个数值"为什么是这个数"和"不这么写会怎样"。
平台 AI 读一遍源码 + 一遍规格，胜过我们写十段提示词。传不进去再退回逐段粘贴。
