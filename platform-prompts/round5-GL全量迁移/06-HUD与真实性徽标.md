# R5-06 · HUD 与真实性徽标（F6 红线，不许跳过）

**配套上传**：`materials/gl/screenshots/01-开场-3D楼群与金线.jpg`（HUD 位置对照）

> 前置：R5-05 通过。
> **这一步不是装饰。** 地图上同时存在真实数据（瓦片路网、真实建筑）和演示数据
> （光位、附近追光者、示例照片）。不把两者标清楚，就是拿演示当真实卖——这是我们的红线。

## 粘贴给平台 AI（第一段：顶部读数）

```
地图上层加两个悬浮胶囊，位置在页面顶部往下 96px，左右各留 14px 边距，
底色 rgba(14,17,26,0.72)，背景模糊 10px，1px 白色 12% 描边，圆角胶囊：
- 左边：小字"距峰值"，接一个 15px 加粗的等宽数字，颜色 #ffd49a，单位"分钟"。
  峰值已过就显示"已过"。
- 右边：一个 8px 圆点（填当前太阳光色，同色发光）+ 等宽小字
  "☀ 283° · 高 7.0°"，10.5px。
这两个胶囊不拦截触摸，手指划过去要能直接拖动地图。
```

## 粘贴给平台 AI（第二段：真实性徽标，这段是重点）

```
地图左上角（顶部往下 140px）竖排四行小字，9.5px 等宽字体：
第一行（绿色 #8fd9a8）：道路·瓦片实时 ｜ 建筑·视口实时 N 栋
  —— N 填当前视口真实构建的建筑数量。如果用的是离线兜底数据，
     必须改写成"建筑·离线包兜底 N 栋"，不许含糊。
第二行（白色 60%）：太阳·实时方位 ｜ 路线·真实路网
  —— 如果太阳位置用的是演示值而不是实时计算，必须写"太阳·演示光位"。
第三行：一个橙色小圆点 + 文字"附近追光者（演示）"
  —— 地图上那几个橙色光点是演示数据，这五个字必须一直显示。
第四行（白色 35%）：操作提示 + 版本号，例如
  "拖动=平移 · 双指/右键=旋转俯仰 · 滚轮=缩放 · v4.9"

这四行的作用是让任何人截一张图就能分清哪些是真数据、哪些是演示数据。
不许把它们做成折叠、悬停、或者只写在说明页里。
```

## 粘贴给平台 AI（第三段：底部结论卡）

```
页面底部往上 96px 放两块：
1. 机位胶囊横滑条：选中的用主题橙 #ff8a3d 底 + 深色字，
   未选中的用白色 10% 底 + 白字，圆角胶囊，可横向滚动。
2. 结论卡：底 rgba(14,17,26,0.74)，背景模糊 14px，圆角 18，
   上面一行小字写"往<方向> · <机位名>"，
   下面一行 14.5px 加粗白字写结论，三种情况分别是：
   - 来得及：步行 N 分钟 · HH:MM 到 · 正好赶上
   - 来不及：步行 N 分钟 · 到时峰值已过 N 分钟 · 抓紧
   - 已过峰值：今晚已过峰值 · 明晚黄金时刻见
   这三句是根据"当前时间 + 步行时长 + 峰值时刻"算出来的，不是随机挑一句。
```
