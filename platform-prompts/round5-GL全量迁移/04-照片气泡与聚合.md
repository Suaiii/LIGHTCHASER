**配套上传**：`materials/gl/bubble_spec.md` + `materials/motion/media/video-04-cluster-zoom.webm`（18s 真交互：缩小合簇→放大散簇→点击展开）+ `materials/data/photos.v1.json`

## 粘贴给平台 AI（第一段：气泡本体）

```
地图上按 photos 数据渲染照片气泡，每条一个可点击的标记：
- 尺寸按新鲜度分三档：1 小时内 80px，24 小时内 64px，更早 48px
- 白色圆角方框：3px 白边、圆角 10、内边距 4，底下是照片缩略图
- 右上角标：新发布的写「刚发布 · 演示」，种子数据写「示例 · X小时前」
- 下方挂一个地名胶囊：底色 rgba(14,17,26,0.86)，白字 9px
- 点击气泡：地图平滑移到该点，缩放至少 15.2，pitch 保持 62，动画 420 毫秒
角标那行是硬要求：「示例」「演示」字样必须一直显示，
不许做成鼠标悬停才出现、也不许只写在说明页里——这些是演示数据，
不标出来就是误导用户。
```

## 粘贴给平台 AI（第二段：聚合，配着视频看）

```
我上传了一段 18 秒的真机录屏，聚合效果照着它做。规则：
1. 地图移动或缩放结束后重排：把靠得太近的照片合成一个"聚合标记"。
   判定距离必须用地面实际距离，不能用屏幕像素距离——
   地图是 62 度斜视角，远处几公里在屏幕上只有几像素，
   用像素会把十几公里外的照片错误合并。
   换算公式：合并距离(米) = 阈值像素 × 40075017 × cos(纬度) / (512 × 2^缩放级别)
   阈值像素：缩放≤12 用 96，13-14 用 72，≥15 用 48。
2. 聚合标记长得像一叠照片：两张白卡分别左倾 7 度、右倾 5 度垫在底下，
   最上面是代表照片；左上角橘色 #ff8a3d 圆形数字角标显示张数。
3. 聚合后角标仍要写「示例 · N 张」或「演示 · N 张」，不许因为聚合就省略。
4. 点聚合标记：放大 1.6 级并居中，放大后自动散开成单张。
5. 缩小自动合并、放大自动解散，不需要用户手动切换。
```

## 粘贴给平台 AI（第三段：三个必须避免的错误，务必单独发）

```
1. 标记的入场动画不要写在标记元素本身上。如果动画带位移或缩放，
   且用了 fill-mode: both，动画结束后的变换会永久覆盖地图库
   给该元素的定位变换，结果是所有标记叠在地图左上角、完全不在地理位置上。
   正确做法：外层容器只负责定位（不加动画），内层元素只负责动画。
2. 不在可见地面上的照片不要渲染：离屏幕中心超过 60 公里的，
   或投影落在画面最上方 16% 那条地平线带里的，或者把屏幕坐标反算回
   经纬度后误差超过 60 米的（说明投影已经翻折到地平线外），一律不显示。
   否则它们会糊在天边，看起来像"照片飘在天上"。
3. 地图有一个闲置慢旋转，旋转每帧都会触发移动结束事件。
   重排前先比较中心点和缩放级别，没变就直接返回，
   否则每帧都在重排标记，手机会烫。
做完把地图缩到全城截图给我，标记应当分散在各自真实位置，不能挤成一堆。
```

## 验收

- [ ] 气泡落在**各自的真实位置**，没有任何一堆叠在角落（这条不过 = 踩了第三段坑 1）
- [ ] 缩小到全城：标记数明显减少、出现带数字角标的"照片叠"
- [ ] 放大回街区：聚合解散成单张，各自归位
- [ ] 点聚合泡：放大并散开
- [ ] **「示例/演示」角标在单泡和聚合泡上都常显**（F6 红线）
- [ ] 静止时不发烫（说明没有每帧重排）
