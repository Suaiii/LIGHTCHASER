# B 档地图规格（平台内置地图组件版）

> **判定背景（2026-07-29）**：平台端 GL 3D 地图**已明确降级到 B 档**。
> A/A− 档（MapLibre + 3D 楼群）的提示词与规格保留在 `../gl/` 与 `round5-GL全量迁移/01–07`，
> 用途改为：①原型侧继续跑，产出演示录屏素材 ②未来复活窗备查。**现场不再赌 A 档。**
>
> 本文件是 B 档的唯一真值源。参考实现 = `source/photo-map.jsx`（原型 2D 地图，Leaflet，
> 已过 HERMES-10 phase2 验收，配 15 张截图 + 3 段录屏，见 `../motion/media/`）。

---

## 0. 降级后：哪些保住了，哪些放弃了

| A− 档的东西 | B 档怎么办 | 叙事还成不成立 |
|---|---|---|
| 3D 立体楼群 | **放弃** | 成立——楼是氛围不是信息 |
| 夜幕调色底图 | 用平台地图的**暗色主题**；没有暗色就叠一层深色蒙版 | 成立 |
| 太阳定向光照 | 换成**光位罗盘**（方位角/高度角 + 顺光/侧光/逆光）+ 顶部天空色带 | **成立，且信息更明确**——光位本来就该是读数，不是靠猜光影 |
| 照片气泡（自定义 marker） | 先探能力：支持自定义 marker 就照做；不支持退**原生 marker + 下方照片列表** | 成立 |
| 聚合/散簇 | 自定义 marker 可用时保留；原生 marker 时由列表承担密度 | 成立 |
| 路线金线 | 平台折线组件，颜色照给 | 成立 |
| 闲置自转、生长动画 | **放弃** | 成立 |

**结论：B 档丢的是"氛围"，没丢"信息"。** 追·光的承诺是"此刻此地的光值不值得出门"，
这句话靠读数和照片就能兑现，不靠 3D 楼。演示叙事按这个口径讲，不要为丢掉的 3D 道歉。

## 1. 页面布局

```
┌─────────────────────────┐
│ 顶部天空色带  6px        │ ← 颜色随太阳高度角变（7 锚点表）
│ ┌─────────┐ ┌────────┐  │
│ │今天│本周 │ │ 光位罗盘│  │ ← 筛选胶囊 136×36，上边距 12
│ └─────────┘ └────────┘  │
│                          │
│        地图区 60vh        │ ← 平台内置地图组件，暗色主题
│   机位点 / 照片点 / 金线   │
│                          │
├─────────────────────────┤
│      照片列表 40vh        │ ← 固定，可滚动
│  [缩略图] 机位名  2小时前  │
│           1.4km  「示例」  │
└─────────────────────────┘
```

- 筛选胶囊：宽 **136px**、高 **36px**、上边距 **12px**，双段「今天 / 本周」，默认今天。
- 时区固定 `Asia/Shanghai`；「今天」= D0 00:00 至此刻，「本周」= D-6 00:00 至此刻（滚动七日，**不含未来时间**）。
- 空集合显示「这一档还没有照片」，**不许回填另一档伪装有数据**。

## 2. Marker 能力探针（先探再做）

| 探到 | 做法 |
|---|---|
| 支持自定义 HTML/图片 marker | 照 `../gl/bubble_spec.md` 做照片气泡：48/64/80 三档尺寸、3px 白边、右上「示例/演示」角标、下方地名胶囊 |
| 只支持原生点标记 | 地图上用原生点（追光橘 `#ff8a3d`），**信息全部由下方列表承担**；每个列表项带「示例」角标 |
| 不支持点击事件 | 退 C 档（录屏内嵌 + 照片时间流），见 `bubble_spec.md §8-C` |

**联动是 B 档的核心体验**（没有这个，地图和列表就是两个不相干的东西）：
- 点地图上的点 → 列表滚到对应项并高亮 1.2s
- 点列表项 → 地图居中到该点（不放大，避免来回跳）
- 详情 bottom sheet 高 **56vh**（最小 360、最大 520），顶部圆角 27，入场 350ms

## 3. 光位罗盘（B 档保住"追光"身份的关键控件）

右上角一张小卡，**这是 3D 光影的替代品，不是附属品**：

```
┌──────────────┐
│ ☀ 283° · 高 7.0°│   ← 等宽字体，10.5px
│  ◐ 侧光 · 好拍   │   ← 受光关系
│  太阳·18:40 实算 │   ← 数据来源，9.5px
└──────────────┘
```

- 底 `rgba(14,17,26,0.72)` + 模糊 10px + 1px 白 12% 描边，圆角胶囊。
- 太阳位置**三档来源**、**禁止写死角度**——完整规则见 `round5-GL全量迁移/07-太阳光照系统.md` 第一段，B 档一字不改地沿用。
- 受光关系 = 相机/路线朝向与太阳方位角的夹角：<45° 逆光、45–135° 侧光、>135° 顺光（口径同 `agents_output/02/light_engine.js` 的 `lightRelation`，不另立一套）。
- 罗盘可选画一个 24px 圆盘：外圈刻度，一个橙点标太阳方位，一个白点标当前朝向。做不动就只留文字，不影响达标。

## 4. 顶部天空色带（零成本保留"光在变"）

页面最顶 **6px** 高的横条，颜色按太阳高度角在 7 锚点间插值：

```
-6°→#5A3870  0°→#8A4068  3°→#C84858  8°→#DE6B48
16°→#E0A060  30°→#EBC28E  55°→#F2E2C4
```

一根色条 + 一个罗盘读数，就把"光在变"这件事说清楚了，成本几乎为零。
掉了 3D 之后，这两样是追·光视觉身份的最后锚点，**不许省**。

---

## 5. 路线

- 平台折线组件：外 `#ff8a3d` 宽 16 半透明（做得到就做辉光），芯 `#ffd49a` 宽 4.5。
- 只支持单色单宽度 → 用 `#ff8a3d`，宽 5，不勉强。
- 终点标记 + 机位名胶囊（底 `rgba(14,17,26,0.82)`，字 `#ffd49a`）。
- **按需出现**：默认不画，用户点「按金线去这里」才画；关闭后 150ms 内移除。

## 6. F6 红线（B 档一条都不能少）

1. 每条演示/垫图数据的「示例」「演示」字样**常显**——气泡上、列表项上、详情卡上三处都要有，不许只靠 hover 或说明页。
2. 左上三行数据来源：太阳（实时/演示时刻实算/表兜底）、天气（实时/默认晴天未接）、地图（瓦片来源）。
3. 地图数据署名按平台组件要求保留。
4. 不显示虚构的在线人数、热度值。
5. 位置模糊化：未取得 `location_ok` 的照片坐标四舍五入到 **0.01°**，正式版自由散点吸附到 **0.002°** 网格。

## 7. 验收基线

| 项 | 达标线 |
|---|---|
| 地图可见 + 可拖动缩放 | 必须 |
| 机位/照片点落在正确位置 | 必须 |
| 点地图↔点列表 双向联动 | 必须 |
| 今天/本周切换后集合真的变 | 必须 |
| 光位罗盘读数随时刻/城市变 | 必须（写死角度即不达标） |
| 天空色带随时刻变色 | 必须 |
| 「示例/演示」三处常显 | 必须（F6） |
| 照片气泡形态、聚合 | 尽力（取决于 marker 能力） |
| 路线金线 | 尽力 |
