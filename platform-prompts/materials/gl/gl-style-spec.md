# 追·光 GL 地图页 · 风格规格（真值版，抽自原型 light-map-gl.jsx v4.9）

> 用途：P4/P5 阶段喂给平台 AI 的唯一视觉事实源。所有色值/参数来自已验收原型，不许它自行发挥。

## 1. 底图与相机

| 项 | 值 |
|---|---|
| 样式源 | `https://tiles.openfreemap.org/styles/liberty`（免费无 key；域名不可达时备选 cartocdn dark-matter） |
| 初始视角 | pitch **62°**，zoom **14.65**，中心=路线中点（demo 可用深圳湾 [113.9819, 22.5238]） |
| bearing | **太阳方位角 − 60°**（受光面入画；太阳方位角用 suncalc 按当前时间/坐标算） |
| 3D LOD 区间 | zoom 14.6–15.4 之间建筑由平到立（低于 14.6 只留 2D 剪影） |
| 页面底色 | `#141824` |

## 3. 路线（按需出现，压过气泡层）

| 层 | 样式 |
|---|---|
| 辉光层 | line `#ff8a3d`，宽 16，blur 8，opacity 0.5，圆头圆角 |
| 芯线 | line `#ffd49a`，宽 4.5 |
| 脉冲点 | 白色 circle r5，blur 0.35，沿路线循环移动 |
| 终点标记 | `#ffd49a` 圆点 16px + 发光，下挂机位名胶囊（深底 `rgba(14,17,26,0.82)`，字色 `#ffd49a`） |

## 4. 照片气泡（数据源 = photos 表，完整规则见 bubble_spec.md）

- 尺寸按新鲜度：<1 小时 **80px** ／ <24 小时 **64px** ／ 更早 **48px**；白边 3px，圆角 10。
- 角标：新发布=「刚发布 · 演示」，种子=「示例 · X小时前」——**"示例/演示"字样必须常显**（F6 红线，不许只放 hover）。角标底 `#303848` 白字。
- 地点标签：气泡下方胶囊，底 `rgba(14,17,26,0.86)`，字 `#f2f3f5` 9px。
- 点击气泡：相机 easeTo 该点（zoom ≥15.2，pitch 62，420ms）。

## 5. 动效（自制，不依赖平台内置；完整清单见 motion/motion_spec.md）

| 名称 | 参数 |
|---|---|
| 气泡入场 zgPhotoIn | 0.4s `cubic-bezier(.16,.85,.25,1.12)`，上浮+缩放+去模糊，逐个错峰 ≤180ms |
| 新照片冒泡 zgPhotoPop（招牌） | 0.68s `cubic-bezier(.16,.85,.25,1.25)`，从 0.2 弹到 1.16 回 1，带橙色高亮圈 |
| 气泡退场 zgPhotoOut | 0.24s ease-in，下沉+缩小+模糊 |
| 终点脉冲 zgChaserPulse | 2.2s ease-in-out 无限循环，scale 1→1.5→1 |
| 闲置慢旋转 | 无操作数秒后 bearing 缓转；用户触摸立即停，松手 4s 后恢复 |
| 无障碍 | `prefers-reduced-motion` 时关闭循环动效 |
