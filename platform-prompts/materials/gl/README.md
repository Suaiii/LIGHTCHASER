## 截图是怎么来的

本地原型 Playwright 真实抓取（402×874 视口，2x），**不是合成图、不是设计稿**。
每张的相机参数记在 `gl-migration-spec.md §11`，平台复现时逐项对照。
抓取环境是软件渲染（SwiftShader），真机 GPU 只会比这更好看。

## 一句话说明这包解决什么

3D 地图迁移最容易死的不是"做不出来"，是**做出来但一堆隐性缺陷**：气泡叠在角落、楼突然蒸发、
标签堆成乱码、静止时手机发烫。这些我们都踩过并修好了，
`gl-migration-spec.md §9` 那 16 条就是账单——照着躲，能省下我们花掉的那几天。
