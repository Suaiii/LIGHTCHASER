# 封面卡六场景 · 版式规格（源：PR #45 `assets/figma/lightchaser-six-photo-scenes.svg`）

> 用途：给**抖音AI平台的生成 AI**照着做卡片版式，也给我们自己核对还原度。
> 所有坐标基于单卡画布 **430 × 860**（拼版原图 1450×1994 已按卡拆分，见 `cards/`）。
> 数值全部从 SVG 源码逐条抄出，**不是目测估算**。

## 1. 画布与三层压暗

| 层 | 几何 | 值 |
|---|---|---|
| 背景照片 | 0,0,430,860 | `preserveAspectRatio="xMidYMid slice"`（等比裁切填满，不拉伸） |
| 顶部压暗 `topShade` | 0,0,430,**430** | 纵向渐变 `#070b17 @.78` → `#111827 @.14`(62%) → `#111827 @0` |
| 底部压暗 `bottomShade` | 0,**522**,430,338 | `#110d17 @0` → `#180d1d @.52`(38%) → `#100b11 @.92` |
| 全幅暖调 `warmTint` | 0,0,430,860 | 纵向 `#6e51a5` → `#e47143`，**整层 opacity .10** |

三层顺序不可换：照片 → 顶压 → 底压 → 暖调。暖调放最后，是让六张来源不同的照片**统一到同一个色温**里——这是这套稿子"六张不同照片看起来像一个产品"的关键，不是装饰。

## 3. 文案槽位 → 我们的数据源

结构化取值见 `scenes.json`（6 条全量）。绑定关系：

| 槽位 | 例（场景 01） | 数据来源 |
|---|---|---|
| `headline` | 蓝调仅剩18分钟 | `sun_events` 的下一个事件 + 倒计时；文案由 AGENT_03 文案引擎生成，**≤26 字** |
| `score` | 91 | 评分公式，见 `agents_output/09/prompts/04-cover-wiring.md` ③（基础 60 + 低云/能见度/湿度修正） |
| `score_label` | BLUE HOUR | 场景枚举（blue hour / sunray / sunrise / walk light / camp picnic / night glow） |
| `verdict` | 正是时候 | 三档标签：≥75 / 45–74 / <45 |
| `spot_name` | 湖岸蓝调 · 灯影机位 | `spots.v1.json` 的 `name`（**必须真实机位**，不许现编） |
| `spot_meta` | 1.4km　步行 11 分钟　最佳 19:18 | 距离=定位与 spot 直线距；步行时长=OSRM；时刻=`sun_events` |
| `reason_line` | 沿着雪地脚印，等天空慢慢变蓝 | AI 文案，**≤15 字**（本稿 6 条实测 9–15 字，含标点全部达标，场景 06 的 15 字踩线） |

## 5. 已知偏差与待办（如实记录，不隐瞒）

**A. 与 `agents_output/04/tokens.md` 的色彩冲突**
- 强调色：本稿 `#ff9f40`，token 定义的追光橘是 `#ff8a3d`。
- 本稿新引入酒红 `#651938` / `#a4385a`，而 token 写明"**唯一强调色**"。
- 评分数字用 PingFang 斜体，token 指定的是 Fraunces；时刻未用 JetBrains Mono。
- → **不擅自改队友的稿**。要不要统一到 token，由负责人拍板；若统一，只需全局替换两个色值 + 换两处字体族。

**B. F6 红线：六张卡都没有「示例/演示」角标**
分数、倒计时、距离、步行时长全是设计稿编的值。**上平台演示前必须补常显角标**（不许 hover 才出）：建议 44×16 胶囊置于评分卡正下方（`282, 245`），文案「示例数据」，底 `rgba(10,10,13,0.88)`、白字 10px、对比度 ≥4.5:1，与 `agents_output/10/bubble_spec.md §7` 同规格。

**C. 背景照片来源未标注（三件套空）**
6 张 JPEG 内嵌在 SVG 里，PR 未附 `credit` / `consent_ref`。按 F6，`sample_img/credit/consent_ref` 须同空或同非空。
- 需队友（@Flyme886）补来源；来源不明的**只能当"版式参照"给平台 AI 看，不能作为对外演示的卡面**。
- **场景 06 另有隐私问题**：夜市照片含可辨认人脸多张，且招牌上手机号清晰可读。对外用前必须换图或打码。
- 六个机位名（湖岸蓝调/云隙光/海岸线/绿荫公园/松林营地/夜市入口）**不在 `spots.v1.json` 的 25 条里**，是稿子占位名。真上线要么换成真实机位名，要么标"示例"。
