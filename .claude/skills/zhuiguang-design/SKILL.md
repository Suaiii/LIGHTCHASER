# 追·光 设计判断引擎

> 改编自 MIT 开源项目 [StyleSeed](https://github.com/bitjaru/styleseed)（连贯性法则/评分门）与 [UI Craft](https://github.com/educlopez/ui-craft)（启发式评分），按追·光第一性原理重加权：**F1 前 5 秒定生死（体验完整性占评审 30%）**。
> 权威 token 值以 `agents_output/04/tokens.md` 为准；本文件是"怎么判断"，不是"值是多少"。

## 一、前 5 秒法则（最高优先级，覆盖其他一切规则）

评委刷到卡片的瞬间就是评审现场。任何设计决策先过这四问：

1. **0.5s**：评分大数字可读了吗？（数字是 payload——**永不动画化 payload**：评分、时刻、机位名必须瞬时完整出现，不淡入、不数字滚动、不打字机）
2. **1.5s**：能看懂"今晚值不值得出门"吗？（等级标签 + 色彩情绪一起说话）
3. **3s**：产生第一次交互欲了吗？（行动句 + 可见的滑动暗示）
4. **挡路即砍**：任何在前 5 秒内出现的装饰、引导浮层、多余信息——删。

## 二、连贯性法则（10 轴，每轴只选一，混用 = lint error）

AI 产 UI 显"假"的头号原因不是丑，是**不连贯**。逐轴检查，追·光已锁定的值直接写在轴上：

| 轴 | 追·光的唯一选择 |
|---|---|
| 圆角 | 软圆角一族（卡片 16-20 / 控件 8-12 / 胶囊仅用于 pill 标签），全局统一 |
| 阴影 | 发光式(glow)而非投影式——深色底上用主色/天空色的低透明度光晕，同一族 |
| 强调色 | **只有追光橘 `#ff8a3d`**（+语义红绿）。第二个装饰性强调色 = 违规 |
| 间距 | 4px 基网格（视口 402×874 紧凑），所有 margin/padding 为其倍数 |
| 图标 | 单一族、线性、同一描边粗细；**禁 emoji 当 UI 图标** |
| 字阶 | Noto Sans SC 主 + Fraunces 展示衬线 + JetBrains Mono 数据，≤3 族已到顶，不再加 |
| 动效 | 一套时长（120/350/420ms）+ 一族缓动（见下），进出逻辑全局一致 |
| 边框 | 1px 低对比 `rgba(255,255,255,0.08-0.12)`，不用边框做层级分隔（用色调+光晕） |
| 状态层 | hover/press 用同一透明度阶梯，所有可交互元素一致 |
| 深色底 | `#0a0a0d` 唯一基底；卡片浮起靠色调差不靠白边 |

## 三、动效词汇（5 seeds，报动效时必须用命名词汇，禁"随便加个 fade"）

| Seed | 气质 | 追·光用在 |
|---|---|---|
| **silk** 丝滑 | 平滑优雅连续 | 卡片入场/页间过渡（现行 `cubic-bezier(.16,.9,.18,1)` 420ms 即 silk） |
| **snap** 利落 | 瞬时果断精准 | 时间条拖动跟手、tab 切换、控件反馈（120-150ms） |
| **spring** 弹性 | 活泼有生命力 | 主 CTA 按压、发布成功 |
| **pulse** 脉动 | 节律性活着 | 峰值倒计时、"此刻直播中"状态点 |
| **float** 漂浮 | 失重梦幻 | 仅限封面天空粒子/光晕等氛围层，不用于信息元素 |

**两条反规则压倒一切**：① 一个产品一种主 seed（追·光 = silk 为主、snap 为辅）；② **永不动画化 payload**（见前 5 秒法则第 1 条）。
`prefers-reduced-motion` 必须有降级（关氛围层、保瞬时切换）。

## 四、设计评分门（改 UI 后必须跑，<80 不给人看）

对目标文件按六类打分（满分 100），**逐条扣分必须引用行号证据**，不许凭感觉：

| 类目 | 权重 | 扣什么 |
|---|---|---|
| **前 5 秒信息效率** | **30** | payload 被动画化(−10)；0.5s 内评分不可读(−8)；首屏信息>3 个焦点(−5)；装饰挡主信息(−5)；无滑动暗示(−4) |
| 连贯性 | 20 | 每混一轴 −5（对照上表），封顶 −20 |
| 层级与排版 | 15 | 数字/单位比例失衡(−4)；处处同字重无主次(−5)；行高局促(−3)；字号偏离 tokens 表(−3) |
| 色彩纪律 | 15 | 第二强调色(−5)；纯黑 #000(−4)；语义色滥用到普通状态(−4)；写死 hex 绕过 token(−2/处) |
| 状态与可达性 | 12 | 缺空态/加载/错误(−4/个)；对比度 <4.5:1(−5)；触点 <44px(−3)；无焦点可见(−3) |
| 动效纪律 | 8 | 未命名的随手 fade(−3)；动效阻塞内容(−4)；无 reduced-motion(−3) |

输出格式：总分 + 逐类分 + 证据行号 + **按"提分收益"排序的 fix-first 清单**（不是按严重度）→ 修 → 重打，循环至 ≥80。80 是地板不是天花板，到 85 就停，别磨到 100。

## 五、Gate 2 盲测预演（Nielsen 精简版）

上真机前用五问走查（1-5 分，≤3 必须修）：
1. 系统状态可见吗？（加载中/数据来源/倒计时还剩多少）
2. 撤销容易吗？（滑错页能一步回来）
3. 一致与标准？（滑动方向符合抖音肌肉记忆：上下切内容、左右切子页）
4. 识别优于回忆？（图标都有文字伴随，不考记忆）
5. 零讲解可懂？（陌生人 5 秒说出"这卡让我干什么"——Gate 2 原题）
