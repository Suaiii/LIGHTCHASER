# AGENT_02 ｜ 光线引擎（评分公式 v2 + 太阳预计算 + 顺逆光判定）

执行者：AI 主导，H2 验收 ｜ 时间窗：7.12–7.20 ｜ 上游：AGENT_01 的机位坐标 ｜ 下游：AGENT_03/05、平台数据表

## 1｜第一性原理
F3：卡片的核心承诺是"此刻的光值不值得出门"——这个判断必须**可解释、可复算**，评委问"分数怎么来的"时答案是一页公式而不是黑盒。F4：平台能否调外部 API 未知，但太阳位置是纯几何——**一切可离线预计算的必须预计算**，让光线数据零外部依赖。

## 2｜上下文胶囊
评分驱动 feed 卡大数字与全部文案基调；等级：≥75 值得跑出门／45–74 顺路看看／<45 今天歇着。数据以 `sun_events`、`weather_daily` 两张表进平台数据库；天气有"在线 API"与"每日人工刷新"双预案（选型待 AGENT_06 测绘结果）。

## 3｜目标（Goal）
产出三件套：① 深圳全部机位 7.24–8.10 的太阳事件预计算表；② 评分公式 v2 的一页纸规格 + 参考实现；③ 顺/逆/侧光判定函数——三者合起来让"任意一天、任意机位"的光线判断在 1 秒内可得、离线可用、人工可验。

## 4｜输入
- AGENT_01 的 `spots.v1.json`（坐标 + bearing）
- SunCalc 算法（初赛已用，纯数学可离线跑）
- 公开气象数据结构参考（云量分层/湿度/能见度/天气码）

## 5｜交付物
1. `sun_events.v1.json`：每机位 × 每日（7.24–8.10）：`sunset, golden_start, golden_end, blue_start, blue_end, azimuth_10min[]`（16:00–20:30 逐 10 分钟太阳方位角与高度角）。
2. `score_spec.md`（一页纸）：公式、权重、每个因子的曲线说明、3 个真实日期的完整算例。建议基线（可在验证中调参）：
   `score = 100 · clamp( 0.35·f_cloud + 0.20·f_humidity + 0.20·f_visibility + 0.15·f_sun + 0.10·f_air )`
   f_cloud：中高云覆盖 30–60% 为峰的钟形曲线，低云 >70% 直接压至 ≤0.2；f_humidity：40–70% 平台区；f_visibility：10km 饱和递增；f_sun：距日落 ±40min 窗口因子；f_air：天气码惩罚（雨/雾/霾）。
3. `light_engine.py`（或 js）：`score(weather, sun)`、`light_relation(bearing, sun_azimuth) → 顺光|侧光|侧逆光|逆光` + 一句机位级光位描述（供 P3/P4 文案）。
4. `weather_ops.md`：双预案 SOP——A 在线 API 字段映射；B 人工刷新（数据来源、每日 08:00/16:00 两次、录入平台的操作步骤、值守人）。

## 6｜交付条件（DoD）
- C1 sun_events 覆盖 = 机位数 × 18 天，无缺行；spot id 与 AGENT_01 完全一致。
- C2 任取 3 天，日落时刻与权威天文数据源核对误差 ≤3 分钟（深圳 7 月底日落应在 19:05 前后）。
- C3 azimuth_10min 单调性与量级合理（傍晚方位角位于西侧象限且随时间递增）。
- C4 score_spec 的 3 个算例可由第三者仅凭一页纸手工复算，结果与参考实现一致（±1 分）。
- C5 光位判定对 4 个方位的合成用例输出符合摄影常识（bearing 朝西 + 太阳在西 = 逆光）。
- C6 用近三日深圳真实天气回测：三天分数排序与当晚实际天空质量的主观排序一致（两人独立打分后比对）。

## 7｜检查任务
- K1 运行覆盖率脚本（机位×日期矩阵），粘贴统计输出。
- K2 与权威源核对 3 个日落时刻，截图存档。
- K3 输出 7.28 各机位 golden hour 一览表——直接交 AGENT_07 排实拍路线（顺手产出，一鱼两吃）。
- K4 极端输入健壮性：云量 100%、能见度 0、雨天代码 → 分数落在 <45 劝退档且无报错。
- K5 请一位队外朋友仅读 score_spec.md 复算一例，记录其卡壳点并修文档。

## 8｜禁区与红线
不引入需付费或需密钥才能复现的数据依赖进入"离线三件套"；公式因子不超过 5 个（可解释性优先于拟合精度）。

## 9｜升级条件
回测排序与主观不符且调参两轮仍不符；预计算体积超过平台导入上限（等 AGENT_06 报数）；发现 bearing 数据系统性错误 → 退回 AGENT_01。
