# AGENT_01 ｜ 机位库构建

执行者：AI 主导，H2 验收 ｜ 时间窗：7.12–7.20 ｜ 上游：无（可即刻开工） ｜ 下游：AGENT_02/03/05、平台数据库导入

## 1｜第一性原理
F3：评委在深圳亲手体验，卡片推荐的每一个机位都可能被当场检验。→ 机位不是"内容"，是**结构化事实**：坐标、朝向、时段错一个，导航与光线判定就全错。F2：平台靠数据库表驱动卡片。→ 本任务的 JSON 就是产品的地基。

## 2｜上下文胶囊
产品为晚霞/城市光影主场景 + 展览/创意园扩展场景的机位推荐（见 AGENT_00 §2）。深圳为样板城市。数据将以 JSON 附件导入抖音AI平台数据库表 `spots`。

## 3｜目标（Goal）
产出一份 **25 个深圳机位** 的结构化 JSON（晚霞/滨海 ≥14、天际线 ≥4、展览/创意园 ≥5、街区咖啡 ≥2），每条记录可直接驱动 P2 导航、P3 攻略、P4 快拍三个页面，且通过自动校验。

## 4｜输入
- 候选地点线索：深圳湾公园、人才公园、前海石公园、蛇口海上世界、大梅沙、莲花山、笔架山、香蜜公园、OCT-LOFT、两馆、海上世界文化艺术中心、欢乐海岸、南头古城（可增删）
- 公开地图服务用于核对坐标
- AGENT_07 陆续交付的样张与署名信息（先留空占位）

## 5｜交付物
1. `spots.v1.json` — 25 条记录，schema 如下（字段全必填，样张三件套除外）：
```json
{
  "id": "szw-001",
  "name": "深圳湾公园 · 日出剧场西侧步道",
  "scene": "sunset | skyline | exhibition | cafe",
  "lat": 22.5213, "lng": 113.9433,
  "stand_desc": "面海栏杆第二个灯柱旁，避开树冠遮挡",
  "bearing": 265,
  "best_window": ["18:40", "19:20"],
  "focal": "24mm 广角收前景 / 50mm 压缩天际线",
  "compose_template": "thirds | leading | silhouette | frame",
  "filters": ["dusk_warm", "film_fade", "mono_city"],
  "sample_img": "", "sample_credit": "", "consent_ref": "",
  "walk_steps": ["步导图1描述", "…（3–5条，最后100米）"],
  "copy_slots": { "hook": "", "tip1": "", "tip2": "", "tip3": "" },
  "tags": ["免费", "地铁9号线", "人少侧"]
}
```
2. `validate_spots.py` — 校验脚本：字段完整性、坐标在深圳市域范围、bearing∈[0,360)、scene/compose_template 枚举合法、best_window 时间格式、id 唯一。
3. `spots_readme.md` — 每个机位一行来源备注（信息线索来自哪里，供追溯）。

## 6｜交付条件（DoD，逐条二元判定）
- C1 记录数 =25，场景配比达标。
- C2 `validate_spots.py` 运行输出 0 错误。
- C3 抽取任意 3 条，坐标在地图上人工核对，落点与 stand_desc 描述一致（误差 <30m）。
- C4 每条 bearing 与该机位实际拍摄朝向一致（晚霞类机位 bearing 应大体朝西 240–300 区间，例外须在 readme 说明理由）。
- C5 `sample_img/sample_credit/consent_ref` 三字段要么同时为空（待授权），要么同时非空且 consent_ref 指向 AGENT_07 台账行号。
- C6 无任何字段内容抄自小红书/抖音笔记原文（表述均为重写）。

## 7｜检查任务（交付前逐条执行，结果写入检查报告）
- K1 运行校验脚本，粘贴完整输出。
- K2 随机 3 机位 × 地图截图核对，截图存 `/agents_output/01/checks/`。
- K3 对全部 sunset 类机位画 bearing 分布表，标注例外及理由。
- K4 用一条记录手工模拟 P3 页渲染（把字段逐个填进页面草图），确认没有"页面需要但表里没有"的字段；如有，先改 schema 再交付。
- K5 交叉比对 AGENT_02 的 sun_events 表：spot id 集合完全一致。

## 8｜禁区与红线
- 禁止直接复制他人笔记文字与图片；样张字段宁空勿假。
- 禁止编造不存在的地点细节（stand_desc 无把握就写保守版本，标记"待 7.28 实地核"）。

## 9｜升级条件（停手问人）
候选机位凑不满 25 且补充线索枯竭；同一地点多来源坐标冲突 >100m；schema 需要增删字段。
